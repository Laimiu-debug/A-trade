# A-trade HTML 前端预览

2026-10-11：本目录同时由 Electron 桌面开发版复用。浏览器使用说明仍适用于独立预览；通过仓库根目录 `npm start` 启动时，笔记和配置保存到本机文件，具体见 [桌面开发说明](../docs/development.md)。两种运行方式均保留业务演示标识。

本轮用于评审真实浏览器中的布局、图标、动效与操作流程。全部股票价格、账户资产、资讯和研究结果为合成示例。

## 打开方式

- 双击本目录 `index.html`，使用 Edge 或 Chrome 打开。页面资源全部在本地，无 CDN、字体下载或接口请求。
- 推荐在仓库目录运行 `node preview/serve.cjs`，然后打开 `http://127.0.0.1:4173/`。服务仅监听本机，按 Ctrl+C 停止；可通过 `PORT` 环境变量更换端口。
- 建议 1440 像素及以上宽度评审桌面布局。窄窗口自动折叠侧边栏，通过顶部当前页面名称展开二级页面。

## 可体验的交互

- 五个模块、17 个侧栏业务入口；保留 50 个原始视图编号作为功能/详情和旧链接兼容。
- 总览标题为“里程碑”。支持滚轮、拖动、左右方向键、Home / End；垂直滚轮向上浏览后面的阶段，向下回看前面的阶段，触控板横向手势保持原生方向。目标收益和阶段数在账户数据中配置。
- 里程碑进度条带 HUD 微刻度、扫描流光和进度端点脉冲，跟随“柔和光效”的开关与强度；减少动画时保留静态样式，页面隐藏时暂停动画。
- 鼠标位于里程碑区域时，滚轮始终由轨道处理，到达两端也不会带动整页。移出后恢复正常页面滚动。
- 点击里程碑打开操作与事件抽屉：按日期合并交易和事件，提供全部 / 交易操作 / 日期事件筛选、上一阶段 / 下一阶段切换。交易展示数量、价格、金额、费用、操作后持仓及信号日期；股票可打开日线，返回恢复抽屉与筛选位置。
- 可补记事件日期、类型、标题、内容与关联股票，按账户和阶段保存到浏览器。前三阶段提供演示档案；未开始的阶段显示空状态，不生成虚构的已执行操作。
- 页面弱化卡片白色描边、投影和导航分界，资产数字以连续分组展示，保留可调节玻璃与光效。
- 收益、回撤、基准、行情曲线及日线蜡烛图；切换区间、悬停读数、日线缩放。
- 点击曲线或日 K 的日期，打开右侧当天详情：账户交易 / 入出金 / 日期事件，回测策略判断 / 次日执行，个股日线 / 分时示例。方向键选日，Enter 打开；支持日期输入与前后日切换，并保留返回位置。
- 回测交易明细、操作路径和曲线点击共用独立策略操作示例，按任务及参数快照区分，不读取账户流水。旧演示任务缺少完整配置时显示无法追溯。收益平原详情绑定当前止盈、止损、减仓比例和策略选择。
- 日期序列为固定工作日样例，尚未校验交易日历。个股缩放只截取固定日线数据，分时示例开收高低与当日 K 线一致；真实历史分时尚未接入。
- 股票名称和六位代码、板块筛选、当前结果全选、日线详情、返回恢复筛选与勾选。
- 单策略、多策略、选股交集配置；示例策略冲突校验；收益平原热力图与所选曲线联动。
- 多任务标签、并发上限、排队、单项和批量暂停 / 继续 / 停止，刷新后保存演示进度。
- 操作路径、减仓记录、报告库；演示交易录入、CSV 导出、研究摘要下载。
- 情绪估值参数计算、跟踪池、自动保存笔记、显示设置、预览 JSON 备份及配置恢复。
- “设置 → 显示与交互”提供磨砂玻璃、柔和光效、漂浮粒子与渐变颜色：独立开关、总开关、模糊程度、卡片不透明度、光效强度、粒子数量 / 速度、渐变浓度 / 方向 / 自定义双色。支持清透日常、流光氛围、专注阅读三种预设与恢复默认，调整即时生效并本地保存。
- 减少动态效果同时遵循应用开关与系统偏好；速度为 0 时粒子静止，页面隐藏时装饰动画暂停。装饰层不接收鼠标事件，行情涨跌色和图表含义不随配色变化。

## 本轮边界

- 没有连接 TDX、MCP、财务源、资讯源或券商；不执行真实回测、下单或账户核算。
- 任务进度由计时器演示。关闭页面后停止推进，重开后从浏览器保存点继续；不是后台工作进程或真实计算断点。
- 回测曲线、指标和操作路径是固定示例，不随策略参数重新计算。新建任务会保存配置供标签切换查看，结果仍用于界面展示。
- 通行证暂按账户示例总资产和逐阶段复利目标计算；入出金调整、回撤、达标确认仍待讨论。两类账户暂共用演示资产和目标配置。
- 平原图是合成切片；减仓比例只影响演示曲线。情绪估值系数暂手动输入，不代表已经确定算法或财务口径的接入实现。
- 设置中的连接、诊断和首次引导为布局样例。JSON 恢复仅恢复通行证配置、任务及回收站、笔记、跟踪池、报告目录、视觉效果与里程碑补记事件；没有正式文件备份服务。
- 状态保存在当前浏览器 `localStorage` 的 `atrade.preview.v1`，不同浏览器、端口与文件打开方式互不共享。清理浏览器数据会删除预览记录。

## 资源与结构

- `tokens.css`：与设计规范对应的语义颜色；`styles.css`：布局、组件状态、动画及响应式规则。
- `effects.css` / `effects.js`：装饰层、玻璃与渐变令牌、粒子生命周期、视觉设置及兼容旧配置的默认值。
- `refinements.css`：连续表面与里程碑抽屉；`milestones.js`：阶段演示档案、日期时间线和事件表单。
- `icons.js`：专门绘制的 SVG 操作与功能图标，延续现有设计板的线条语言。
- `assets/app-icon-sheet.png`：复用 V0.5 应用图标设计；`assets/milestone-sheet.png`：复用 V0.4 波段徽章设计。当前通过裁切视窗展示，正式发布时需整理独立矢量与 Windows 图标包。
- `data.js`：合成数据与页面目录；`charts.js`：SVG 曲线与日线；`views.js`：研究/市场模板；`account-views.js`：账户、交易、复盘和分享的完整页面；`app.js`：导航、弹层和交互。
- `chart-data.js`：带日期的行情及策略独立样例、上下文快照；`chart-details.js` / `chart-details.css`：账户、研究和个股的按日详情。
- `screenshots/`：真实浏览器截图；`verification.md`：本次验证范围。

这是可继续调整的界面原型，尚非正式桌面应用。


## 2026-10-11 交互细节修订

- 模块按钮可展开与收起；所有子页面配有 SVG 图标。窄侧栏保留可点击图标、名称提示及研究任务入口。
- 里程碑抽屉切换筛选时复用原浮层与筛选按钮，保留滚动位置及未提交事件草稿；切换阶段仅更新内部内容，不重播入场动画。
- 回测工作区标签、进度条和任务中心均可删除任务；支持批量删除、十秒内撤销和持久回收站。恢复时保留参数与进度，原运行/排队任务转为暂停，避免自动恢复计算。已保存报告不随任务删除。
- 主蓝、正文/辅助文字、涨跌、回撤、状态和对比曲线颜色统一使用设计令牌。玻璃、光效、粒子、渐变继续由显示设置独立调节。

- 页内按钮刷新统一保持实时滚动位置及焦点，包含曲线切换、任务/策略操作和筛选；表格与任务标签保留横向位置。相同页面入口保持原位置，跨页进入后返回恢复阅读位置。


## 参考 final-trade 的页面职责

依据实际路由、导航和页面内容重整，源文件与映射见 `../docs/references/final-trade-page-structure.md`。

- 账户总览：里程碑、资产、收益和持仓；账户配置和资产快照直接打开弹窗。
- 交易管理：交易/资金流水在原地切换，下接次日计划；导入与对账是页面操作。
- 复盘统计：同页呈现收益与回撤曲线、每日/周期复盘、灵感及操作对照。
- 复盘分享：独立预览卡片与导出摘要，不与灵感笔记捆绑。
- 策略模块侧栏只保留策略中心、回测工作区、报告库；收益平原、研究对比置于工作区内，结果和路径从任务打开。
- 趋势龙头包含连板梯队，情绪估值包含跨行业筛选，异动追踪包含断板再涨停；系统设置使用内部分类。

宽侧栏统一缩进；窄侧栏点击模块时，在旁边展开带图标和名称的子菜单。模块可展开/收起。旧账户地址自动定位对应新页面、内容区或弹窗，原笔记键保持兼容。
