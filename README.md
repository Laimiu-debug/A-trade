# A-trade

面向 A 股的股票复盘项目。

## 当前阶段

2026-10-11 开始分步开发。第一步为 Windows 桌面启动与本地保存：使用 Electron 承载现有 `preview/` 界面，将笔记、显示配置及演示工作区状态保存到本机文件。账户核算、行情接入和回测引擎后续逐项实现，现有业务数字仍为演示数据。

## 启动桌面开发版

需要 Node.js 22.12 或以上版本。首次安装运行 `npm ci`，随后运行 `npm start`。

工作区文件位于 `%APPDATA%\A-trade\workspace\`，与代码和浏览器预览分开。设置 → 应用与诊断中可查看位置、打开文件夹。正常关闭前会等待保存；保存失败时保留窗口并提示处理。

运行 `npm test` 检查文件保存和恢复，运行 `npm run test:desktop` 验证真实 Electron 启动、关闭保存和重启恢复。开发边界、文件格式和逐步验收方法见 [分步开发说明](docs/development.md)。当前通过源码启动，尚未制作安装包。

## 打开前端预览

直接用浏览器打开 [preview/index.html](preview/index.html)，或在项目目录执行 `node preview/serve.cjs`，访问 `http://127.0.0.1:4173/`。无需安装前端依赖。

预览包含五个模块及 50 个页面入口，重点可体验账户通行证、曲线、股票详情、回测配置、收益平原和任务中心。行情、账户与回测结果均为演示数据。交互范围和启动说明见 [预览说明](preview/README.md)，实际检查见 [验证记录](preview/verification.md)。

已确认个人使用，采用 Windows 桌面软件；账户、复盘和研究记录在本机保存，并自动备份。数据来源包括用户自行下载更新的本地 TDX 日线数据，以及接入后自动刷新的通达信 MCP 服务。数据缓存、股票展示与跳转、批量选择规则见需求讨论记录。

已提出“账户与复盘”“市场与行情”“策略与回测”“股市分析工具”和“设置”五个功能模块。账户总览顶部采用长期通行证样式，按账户整体收益推进，目标收益率与阶段数由用户设置；30% 与 70 阶段只是例子。阶段收益口径及达标规则仍待细化。

研究主要以日线为基础，晚间判断并生成下一交易日的买卖计划；回测与收益平原采用相同时序，同时研究收益预期、持仓与退出参数、减仓及部分止盈，以及市场风格转变风险。

回测结果需提供完整操作路径的查看入口，帮助理解每次判断、执行及持仓变化，支持后续操作复盘与研究。

所有研究与回测任务需展示进度条，并支持暂停、恢复／继续运行和停止；退出软件或电脑重启后，可以从保存进度继续。可同时管理多个回测任务，在资源预算内并行运行，其余任务排队；任务中心提供单项及批量控制。

账户复盘、研究与回测重视曲线展示，需提供收益、亏损及其他相关曲线，直观查看整个过程的变化。

分析工具包括情绪估值法、新闻与公告、趋势龙头、板块资金动向、异动股票、断板后再涨停跟踪，以及每日连板高度股票；具体识别口径继续讨论。

设置集中管理数据来源和账户费率，以首次完成必要配置后日常使用尽量无需再进入设置为目标。

已确认补充每日复盘工作台、次日计划与实盘对照、统一跟踪池、交易导入与对账、数据检查、回测验证与研究版本保存、组合仓位管理，以及自动保存、备份与分享隐私功能。

情绪估值采用用户提供的公式，财务数据由软件自动获取，盈利口径为最近 12 个月归母净利润（TTM）；其他系数与财务接口的具体接入方式继续讨论。

已保存情绪估值的公式与界面参考，待架构建立后进一步研究；跨行业寻找估值偏低候选股票作为后续研究方向。

UI V0.5 初稿已整理，默认浅色主题，覆盖 50 个页面与全局视图。本版补充软件主标识、按钮及功能入口的专属图标；通行证沿用 V0.4 波段徽章与滚轮连续轨道，参数进入账户数据配置，保留多任务工作区。早期生成图按版本保留；现已提供真实 HTML 原型，作为后续界面评审依据。

桌面入口采用 Electron，当前复用原生 HTML / CSS / JavaScript 界面。后续业务服务、SQLite、研究进程及界面模块化按原分层架构逐步落地；安装与更新方案、完整首版范围继续细化。
