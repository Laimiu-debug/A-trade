## Windows 便携版

“市场与行情 → 股票池”可独立使用，默认沿用全局本地日线和数据源覆盖的全部 A 股。成交额阈值、当日成交额与 20 日均额以万元显示；内部接口保持元。支持基础 → 趋势 → 回调结构 → 量能四层累计漏斗，以及自选条件交集／并集；先计算完整名单再搜索和分页，列表提供 K 线与多池归属。股票池筛选独立于策略评分，按当日成交额降序、代码升序排列；入池依据逐项显示实际值、门槛与通过状态。基础不合格证券单列未通过条件，旧报告不补造缺失依据。筛选设置独立保存，可主动带入回测，让策略使用按每日重新计算的叠加池。各层高级条件已借鉴 FinalTrade 的全池涨幅排名、均线累计/连续天数、峰值与 MA20 位置、涨跌量关系和三类量价风险，可分别启用；[计算口径与差异](docs/stock-pool-filters.md)明确列出实际公式，不移植缺少真实依据的换手或 AI 题材标签。

0.4.1 便携版包含统一策略工作区、Electron、Python 和账户、回测、行情所需运行依赖，完整解压后双击 `A-trade.exe` 即可使用。默认沿用本机现有工作区。打包、数据位置与验证方式见 [便携版说明](docs/portable-release.md)。

回测报告点击净值曲线任一天，直接查看建仓、加仓、减仓、清仓及本笔前后股数、资金变化；仓位区分真实持仓、单股目标上限与可用现金。下一交易日计划分列卖出、买入、方向待定和继续持有，保留延期及分批订单的原计划日期、冻结股数和未成交原因；分红送配单列说明。操作路径合并重复成交记录。旧报告缺少的历史快照需重新回测后生成，详见 [报告显示口径](docs/strategy-backtesting.md#逐日报告与操作说明2026-10-12)。

日常流程是“选股漏斗 → 策略中心 → 策略运行 → 策略回测 → 收益平原”，参数预设与股票池可跨页使用，信号可带入账户计划。组合、轮动、样本外比较与系统参数测试在「组合与系统研究」中设置，既有任务继续保留完整的计算与验证记录。详细计算口径见 [策略工作区接入说明](docs/finaltrade-reproduction.md)及 [组合研究工作流](docs/single-strategy-workflow.md)。

## 启动桌面开发版

需要 Node.js 22.12 或以上版本，以及 Python 3.11 或以上版本。首次安装运行 `npm ci`，随后运行 `npm start`。账户和本地行情读取只依赖 Python 标准库；启用通达信 MCP 前另运行 `npm run setup:market`，在项目自己的 `.venv` 安装 `requirements-market.txt` 中的依赖，然后重启软件。桌面优先使用该环境，也可设置 `ATRADE_PYTHON` 为包含所需依赖的解释器绝对路径。

工作区文件位于 `%APPDATA%\A-trade\workspace\`，与代码和浏览器预览分开。设置 → 应用与诊断中可查看位置、打开文件夹。正常关闭前会等待保存；保存失败时保留窗口并提示处理。

运行 `npm test` 检查文件保存、服务桥接、AI 适配、行情筛选及指标计算，`npm run test:business` 检查 Python 业务逻辑，`npm run test:desktop` 检查 Electron 启动与恢复，`npm run test:account` 检查账户操作和模拟截图识别链路，`npm run test:market` 检查本地行情、研究快照、图表交互与重启恢复，`npm run test:market-live` 检查真实 MCP 协议接入的桌面流程，`npm run test:portable` 检查实际便携版 exe 与内置服务。操作流程见 [账户与复盘](docs/account-workspace.md) 和 [市场数据接入](docs/market-data.md)，参考代码研究见 [导入与评分实现笔记](docs/account-reference-notes.md)。测试覆盖与当次通过结果分别记录；当前提供免安装便携版，尚未制作安装程序。

本轮连板与风格增强的 Node 测试 103 项通过；Python 共 235 项，233 项通过、2 项因 Windows 符号链接权限跳过。分析工具写入／重启读取及资讯桌面流程通过。使用真实通达信目录的后端验证中，M01／T08 的 1000 日共享证据一致，250／1000 日重叠部分一致；实测口径与性能见 [本地分析验证](docs/local-analysis.md#已验证)。

上述结果属于连板与风格增强；本次 T06 监管追踪的验证结果另见 [监管与期限追踪](docs/regulatory-watch.md#验证记录)，目前待验证。

行情从“设置 → 数据源”开始：选择通达信安装目录或其中的 `vipdoc` 文件夹，点击“保存并读取”；启动支持 TQ 策略的通达信并登录行情后，在同页启用 MCP 并检测连接。软件不预设安装盘符，也不自动搜索本机目录。打开“个股行情”查看日 K，双击某根日 K 可在页面内查看该日分时，也可切换一分钟 K 线。分钟数据来自本地 `.lc1`、MCP 或在线近期分时补充，并标明实际来源和日期。

市场总览保留一组主要指数报价，原来重复的指数日线卡片已替换为“市场风格观察”：按本地同一交易日股票的广度与量价统计，默认回看 250 个交易日，可选 60／120／250／500／1000 日；普通风格需连续两日确认，已确认标签 20 个交易日未获续期则显示“风格待确认”，退潮防守与数据不足当日生效。历史不足不会补造记录。板块行情支持搜索、涨跌筛选和列排序；个股及板块成分支持市场、涨跌、MA20、放量与日期筛选，按涨跌幅、成交额、阶段涨幅等排序，并分页查看。成交活跃、涨幅领先和放量观察三个规则池各最多 50 只，按当前筛选范围内的同日行情生成，不冒充外部人气榜。

分析工具可按截至日期读取本地日线，比较 MA20／60、阶段收益、放量与收盘突破，查看近似涨停的断板事件，并将证券加入可保存备注、标签和状态的跟踪池。“连板龙头”提供并列最高板候选、昨日高标的晋级／断板／缺失结果、分层晋级率与历史更替线索；同一时间轴对照最高高度、接力率、趋势成交占比及 MA20 广度，支持 60／120／250／500／1000 日、缩放拖动和回看当日日 K。候选可按交易板、ST 与最低高度筛选；历史统计保持全市场口径。市场总览同步展示这些接力、趋势和风险证据，连板统计与分析工具共用实现，60 日要求只用于相关广度和趋势样本。

晋级率以昨日相应高度且今日可核验的股票为分母，缺失不算失败；没有分母时保留空值。趋势候选需连续 60 日有成交、站上 MA20／60，最近五日的 20 日收益均为正，成交占比不是净流入。涨停按日期对应的名义限价四舍五入到分识别，已纳入主板 ST 自 2026-07-06 起 5% 调至 10% 及创业板历史切点；当前名称不能还原历史 ST，未复权和上市特殊规则等缺口仍保留“近似”提示。规则、来源链接、日期、缓存和验证见 [本地分析工具](docs/local-analysis.md)。跟踪池状态不等于账户持仓。资讯、财报 TTM、实际市值及独立的主力净流入入口使用公开来源，保留报告期、来源时间与缺口，详见 [公开资讯、财务与行业资金](docs/market-information.md)。

T06“异动追踪”按用户明确的用途，展示重点监控、严重异常波动记录与临近来源截止的证券。东方财富证券与广发证券公开名单分来源、分期限保留，支持搜索、类型和市场筛选、三态排序及加入跟踪池。倒计时按已核验的 2025／2026 年交易所休市安排计算，不含今天、包含截止日；预计截止、期限届满或来源移除均不表示已解除监管。当前名单不接受历史截至日查询，旧量价异动接口仅兼容保留。来源与期限边界见 [监管与期限追踪](docs/regulatory-watch.md)。

板块列表增加真实指数近 20 日走势，点击可在页面内查看最多 250 日历史，支持滚轮缩放、左键或右键拖动。行情和分析表格点击列名按“正序 → 倒序 → 复原”切换，复原保留筛选和观察池。情绪估值提供当前同行 PE 中位数、均值、四分位区间，以及独立的近 250 日行业整体 PE 历史参考，可主动采用到情景参数。板块资金页面默认从自选通达信目录读取成交额与热度，可搜索并将最多 5 个板块或分类指数叠加到同一张图，切换成交额、5 日热度或区间涨幅，支持 30／60／120／250／750 日、滚轮缩放及左右键拖动。趋势龙头页对本次候选提供相同的成交额观察，并遵守研究截止日期。独立的“主力净流入”入口保留东方财富逐日净额与累计曲线；该历史接口仍可能断连，不能以成交额替代净流入。

板块页顶部提供头部板块同图对比：默认按全目录最新已读报价选择涨幅前 5 个上涨板块，可切前 3／前 8，或在列表逐个加入、移除，最多同时比较 8 个。各条曲线按所选周期的共同基准日收盘换算为累计涨幅，使用同一百分比坐标轴，支持 20／60／120／250 日和缩放拖动。搜索、分页和后台报价刷新不会自动更换已经选好的对比成员。

日 K 可开关 MA5/10/20、主散量能、金叉／紫转黄，以及箱体突破和突破后的确认标记。指标基于完整已载入历史计算，与日 K 同步滚轮缩放、左键或右键拖动和日期定位；历史不足保留空值。主散量能沿用 FINAL-TRADE 的量价公式，是成交量估算，不是实际资金流；具体公式、确认条件和边界见 [个股图形观察指标](docs/market-indicators.md)。

当前价格未复权；TQ 快照未提供行情时间时显示“行情时间未提供”，采集时间不冒充行情时间。在线源断连时保留有效缓存并提示。本地日线可按所选日期填充账户资产快照，人工确认保存后参与估值；价格来源与日期随快照保留。自动策略执行及 AI 复盘行情上下文仍未接入。

## 打开前端预览

直接用浏览器打开 [preview/index.html](preview/index.html)，或在项目目录执行 `node preview/serve.cjs`，访问 `http://127.0.0.1:4173/`。无需安装前端依赖。

预览包含五个模块及 50 个页面入口，重点可体验账户通行证、曲线、股票详情、回测配置、收益平原和任务中心。浏览器独立预览中的行情和账户保留演示数据；策略与回测显示桌面服务要求，不再生成虚拟收益或任务进度。交互范围和启动说明见 [预览说明](preview/README.md)，实际检查见 [验证记录](preview/verification.md)。

已确认个人使用，采用 Windows 桌面软件；账户、复盘和工作区记录在本机保存。数据源已包含用户自行下载更新的 TDX 文件、本机通达信 MCP 和在线近期分时补充。MCP 参考既有 TRADE 项目的只读桥接方式，A-trade 的运行环境、代码和缓存独立，不依赖旧项目目录。数据缓存、股票展示与跳转、批量选择规则见需求讨论记录。

已提出“账户与复盘”“市场与行情”“策略与回测”“股市分析工具”和“设置”五个功能模块。账户总览顶部采用长期通行证样式，按账户整体收益推进，目标收益率与阶段数由用户设置；30% 与 70 阶段只是例子。阶段收益口径及达标规则仍待细化。

研究主要以日线为基础，晚间判断并生成下一交易日的买卖计划；回测与收益平原采用相同时序，同时研究收益预期、持仓与退出参数、减仓及部分止盈，以及市场风格转变风险。

回测结果需提供完整操作路径的查看入口，帮助理解每次判断、执行及持仓变化，支持后续操作复盘与研究。

所有研究与回测任务需展示进度条，并支持暂停、恢复／继续运行和停止；退出软件或电脑重启后，可以从保存进度继续。可同时管理多个回测任务，在资源预算内并行运行，其余任务排队；任务中心提供单项及批量控制。

账户复盘、研究与回测重视曲线展示，需提供收益、亏损及其他相关曲线，直观查看整个过程的变化。

分析工具已提供情绪估值、新闻与公告、趋势候选、板块资金动向、监管与期限追踪、断板后再涨停、连板龙头与接力对照、统一跟踪池。当前识别规则与数据边界已记录，后续继续校准研究方法。

设置集中管理数据来源和账户费率，以首次完成必要配置后日常使用尽量无需再进入设置为目标。

已确认补充每日复盘工作台、次日计划与实盘对照、统一跟踪池、交易导入与对账、数据检查、回测验证与研究版本保存、组合仓位管理，以及自动保存、备份与分享隐私功能。

情绪估值默认直接展示同日同行 PE 的相对位置、中位数折溢价与行业自身历史位置；无需先填写情景参数。大盘水位从配置行情源读取上证收盘点位，按原模型 `max(0.5, 点位 / 3000)` 展示计算依据，不再重复乘入当前同行估值。原公式移至手动情景，仍采用真实归母净利润 TTM；缺失、零盈利与亏损不生成乘数估值，旧数据保留实际日期与状态。

已保留情绪估值的原始公式与界面参考，并提供按真实行业、名称和代码检索的财务目录。市盈率与情景偏离的筛选排序仅作用于当前来源页；尚未形成全市场公允价值排名，行业参数与低估判定仍需研究验证。

UI V0.5 初稿已整理，默认浅色主题，覆盖 50 个页面与全局视图。本版补充软件主标识、按钮及功能入口的专属图标；通行证沿用 V0.4 波段徽章与滚轮连续轨道，参数进入账户数据配置，保留多任务工作区。早期生成图按版本保留；现已提供真实 HTML 原型，作为后续界面评审依据。

桌面入口采用 Electron，界面使用原生 HTML / CSS / JavaScript。账户业务通过受控进程接口调用 Python / SQLite，AI 请求和密钥管理留在桌面主进程；账户、行情、研究使用独立通信进程；安装与更新方案后续实现。
