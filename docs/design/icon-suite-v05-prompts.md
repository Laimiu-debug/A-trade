## 按钮操作图标

```text

Asset: Complete common BUTTON ACTION ICON family for A-trade, a light Windows desktop equity research app. Static design-review board.
Reference image 1: A-trade existing icon family. Match only the TOP ROW functional icon stroke style, rounded joins, navy and cobalt. DO NOT include crystal milestone badges or decorative hexagons.

Create a beautifully disciplined high-resolution landscape 3:2 board, ideally 2048x1360, white/#F5F7FB, dark navy #172333 glyphs and small #2457E5 accents. Crisp custom outline icon drawing, same 24-unit design grid, ~1.75-unit rounded stroke, optically consistent, no random clipart styles. Draw icons large enough to inspect, not as gigantic solid pictograms. Conventional symbols must remain familiar. One short accurate Chinese label directly under every icon. The board title is "A-trade · 按钮操作图标". Subtitle "统一描边 · 统一圆角 · 统一操作含义". Keep typography small and orderly, icons dominant.

Row2: 搜索 (magnifier), 筛选 (funnel), 全选 (checked square), 清空选择 (empty square with small minus), 刷新 (two circulating arrows), 更多 (three horizontal dots).

No financial recommendations, stock prices, app sidebar, achievement badges, gradients on function icons, shadows on individual glyphs, emoji or watermarks. Clean practical custom designed icon library review, not a code implementation.
```
