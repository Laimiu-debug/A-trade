# 首次使用引导

桌面新工作区在未配置行情、没有账户且未指定页面路由时进入「新手入门」。已有工作区继续恢复原页面；手动指定的页面也优先。入口始终保留在「设置 → 新手入门」，旧 G05 链接仍打开同一引导。

引导按实际进度展示三个步骤，可以点击步骤回看：

1. 连接本地日线。复用数据源设置的目录选择、保存、索引扫描和错误显示。目录里没有证券时不能点亮这一步。没有数据时提示先在通达信下载盘后日线。
2. 检查一只日线。只有用户点击后才从已有日线索引中搜索股票、读取最多120根实际日线，核对身份、日期和价格；只有名称、未下载日线的证券不参与自动抽查。名称有歧义、无索引、无日线、错误证券或过期缓存都不能通过。检查前后核对目录与扫描身份；用户停止后忽略迟到数据。不以单股检查代表全市场完整覆盖。
3. 选择研究方式。说明「加载输入池 → 逐步筛选 → 查看个股」与「选择策略/范围/日期 → 设置交易参数 → 启动回测 → 复核结果」两条流程，并导航到实际入口。打开入口只表示选好研究方式；成功完成回测仍以任务结果为准。

AI、实时行情、账户、费用与备份为可选设置，默认收起。进入引导不会自动请求 AI、扫描股票策略或创建回测任务；账户记账不作为日线研究的前置条件。

连接与检查状态来自真实行情服务。检查结果只保存证券、实际日期范围、数量、检查时间与扫描身份，不保存日线数组、模型配置或目录路径。更换目录、重新扫描或目录不可用时，旧检查不再作为完成依据。

引导进度保存在工作区 `onboarding` 字段，支持稍后设置、重启续接和重新打开。未完成时页面顶部提供继续入口及当前选股/回测操作提示。保存失败时保留当前结果、提示重试，成功保存后才进入研究入口。完成或跳过后不再显示继续横条。

验证：`node --test tests/onboarding.test.cjs`、`npm run test:onboarding`。桌面验收使用隔离配置和真实TDX二进制夹具，跨三个进程检查首次启动、真实索引和日线、停止、重复点击、失败保存与重试、活动进度恢复、完成、换源失效、跳过及重开；不调用外部AI或交易接口。
