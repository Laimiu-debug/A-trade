# 设置与本机备份

## 参数配置

账户费率和仓位规则分别保存。费率单位为万分之，最低佣金单位为元；仓位范围为 0—100%，单股上限不能超过总仓位上限。零值会原样保留。

这些参数目前用于配置记录，尚未自动应用到账本费用或研究计算。成交费用仍以交割单录入值为准。

旧版本共用的 `ruleA`、`ruleB` 无法判断原所属分类，因此升级时保留旧值供查看，新分类使用各自默认值，并提示分别核对保存。

## AI 与数据源

AI 的地址、模型、开关与临时密钥可在本次会话内跨页面保留。保存成功或放弃更改后清除草稿。密钥不进入普通界面状态及备份；已保存密钥继续由桌面主进程加密保管。退出时可返回编辑、保存配置后退出，或放弃 AI 修改。

启用状态和连接检测结果分别显示。检测结果带时间，修改配置后需重新检测；图片接口连接测试不等于实际截图识别验收。

通达信 MCP 可以选择跟随本地日线目录，或使用独立安装目录。跟随模式保存继承关系；本地目录改变后关闭旧连接并清除旧检测状态。原来保存的非空独立路径保持不变。

## 备份范围

设置页分别提供账本、界面状态与真实跟踪池的导出恢复。它们是不同类型的备份，使用对应入口恢复：

| 类型 | 包含内容 |
| --- | --- |
| 账本 | 所有账户、流水、复盘、计划、资产快照及账本导入记录 |
| 界面状态 | 阅读与视觉偏好、侧栏、独立费率与仓位参数、分析常用条件、复盘草稿、历史笔记及演示状态 |
| 真实跟踪池 | 证券、备注、标签、状态及关联研究信息 |

AI 密钥、本机数据源路径、行情缓存、真实研究任务与结果不属于上述界面或跟踪池备份；此处不提供整个应用数据目录的镜像备份。界面备份恢复保留当前页面和账户选择，旧格式备份只替换其中存在的受支持字段。恢复会先校验数据；界面状态写入失败时保留当前内容，真实跟踪池在事务中恢复。

## 显示与诊断

阅读选项位于显示设置顶部；视觉预设在其后，玻璃、粒子、渐变等细项默认折叠。右侧用示例表格与表单展示字号、行距、配色效果。

应用与诊断提供版本、服务进程、界面保存、数据源状态和最近检测时间。刷新只读取本机状态，不主动发起外部连接测试。复制的诊断信息采用字段白名单，不包含账户、持仓、本机路径、接口地址、模型名称或密钥。

## 验证

- `node --test tests/settings-state.test.cjs tests/ai-settings-ui.test.cjs tests/market-settings-ui.test.cjs`：规则隔离、旧值迁移、AI 草稿与连接反馈、目录继承。
- `node scripts/smoke-settings.cjs`：隔离工作区中的设置页交互、备份往返、诊断及宽窄窗口截图。

测试不读取用户的实际工作区，不使用真实 AI 密钥或行情连接。
