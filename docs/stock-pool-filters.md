# 股票池细条件

入口为“市场与行情 → 股票池 → 筛选条件”。每层卡片内的“高级”可分别启用条件，取消勾选即关闭。新细条件默认关闭，旧配置的原有结果保持不变。启用后点击“按当前设置筛选股票池”重新计算；切换交集、并集或分页只重查已保存名单。

这些是股票池资格条件，不执行策略信号、策略评分或 AI 选股。回测使用相同计算，每个交易日只读取当时已经出现的行情。

## 按策略风格配置漏斗

回测工作区连续配置基础可交易池、策略风格条件和交易规则；可以直接运行回测，也可以沿用当前配置做少量参数测试。其他日期验证是结果中的可选操作，组合与轮动在高级研究中另行配置。漏斗决定允许策略研究哪些股票，策略再独立判断当天是否触发入场。

风格预设只替换分层 `poolSettings` 条件快照，不修改数据来源、全 A 股范围、基础资格或策略参数。切换预设时会清除上一预设遗留的高级筛选条件；保存和回测使用实际条件，不依赖预设名称。原有配置保持不变，也可以继续自定义。

| 风格 | 按顺序求交集的条件 | 留给策略判断的内容 |
| --- | --- | --- |
| 仅基础可交易池 | 沿用 ST、上市历史和成交额等基础资格 | 全部入场条件；也可作为其他漏斗的对照组 |
| 突破候选 | 基础 → 收盘高于上行 60 日均线且 60 日涨幅≥0% → 近 20 日最高收盘价回撤 0%–8% | 当天是否突破、是否达到策略放量要求；0% 回撤允许新高，不再被正的回撤下限排除 |
| 趋势回调候选 | 基础 → 同上趋势条件 → 近 20 日回撤 2%–15%、收盘>MA20、MA10>MA20 连续≥3 日 | 当天是否开始回升；不强制回调日放量 |
| 趋势动量候选 | 基础 → 收盘高于上行 60 日均线、60 日涨幅≥5%、完整有效基础池同窗口涨幅排名 1–500 | 策略自身的动量窗口、最低收益和排序；不额外要求回撤形态 |
| 量能活跃候选 | 基础 → 当日成交量/此前 20 日均量≥1.2，并排除近 20 日放量收阴或平盘、近 5 日长上影收阴或平盘风险 | 主散金叉、紫转黄或连续主导；候选池不调用这些公式，也不推断真实资金身份 |

以上参数是开始研究的条件假设，不是经过收益验证的最优值。先比较固定参数下的基础池和相应风格漏斗，再只对少量关键参数做平原测试；不能用多次尝试的最佳结果代替冻结后的独立新时段验证。各项缺失数据仍按本页规则标为未知。

| 所属层 | 条件 | 计算口径 |
| --- | --- | --- |
| 基础 | 20 日平均振幅 | 最近 20 日 `(最高价−最低价)/收盘价` 的均值，包含截止日 |
| 趋势 | 窗口涨幅排名区间 | `截止日收盘价 / N 个交易日前收盘价 − 1`，需要 N+1 根；对基础资格通过且历史足够的完整范围排名，涨幅降序、同涨幅代码升序；起止名次均包含 |
| 结构 | 回撤峰值口径 | 可用窗口内最高收盘价或最高价；默认最高收盘价保持原结果 |
| 结构 | 均线持续性 | 最近 20 日 MA10>MA20、MA5>MA10 的满足天数；可选累计或截至当日向前连续，均最多 20 天；完整比较需要 39 根日线 |
| 结构 | 峰值距今 | 与回撤使用同一窗口及峰值口径；同高取最近一次，今天为 0 |
| 结构 | MA20 位置 | 可独立要求收盘价>MA20，或限制绝对偏离 `abs(收盘价/MA20−1)` |
| 量能 | 20 日首尾量增幅 | `当日量 / 19 个交易日前量 − 1`，不是回归斜率 |
| 量能 | 涨跌量关系 | 近 20 日上涨日均量/下跌日均量；平盘归上涨组；另可限制下跌日均量/全期均量 |
| 量能 | 成交量突增收阴 | 近 20 日任一天量>全期均量×2.5，且收盘≤开盘 |
| 量能 | 上涨缩量背离 | 当前收盘>5 个交易日前收盘，且近 5 日均量<此前 5 日均量×0.9 |
| 量能 | 长上影收阴 | 近 5 日任一天上影线/振幅>0.5，且收盘≤开盘；高低价相等不算风险 |

证据来自该次冻结计算，而非当前尚未提交的表单。每只股票展开“查看逐项对照”可见实际值、条件、状态、统计口径及排名样本数。启用条件所需历史不足、分组为空或分母为零时，记为数据不足，不填造比值，也不当作通过。关闭的条件不影响入池。

## 与 FinalTrade 的对应关系

参考本机 `H:/CODE/FINAL-TRADE/backend/app/models.py` 的 `ScreenerStep1Config` 至 `ScreenerStep3Config`、`tdx_loader.py` 的真实日线派生值、`store.py` 的 Step1–Step3 筛选调用。参考值为排名 1–500、均线累计 5/3 天、峰龄最多 3 天、MA20 绝对偏离 8%、首尾量增幅 5%、涨跌量比 1.3、下跌/全期量比 0.9。界面单项启用时填入对应参考值，不表示这些参数已获收益验证。

有意保留以下明确差异：

- 排名使用通过基础资格且窗口足够的完整样本，不按策略命中、页面或已通过趋势条件的子集排名；不复制 FinalTrade 的隐含 400 只截断，同涨幅使用确定性的代码次序。
- FinalTrade 真实日线路径的均线天数是近 20 日累计次数；这里额外提供连续天数，并要求完整均线观察窗口。
- 峰值日期与回撤采用同一口径，相同峰值取最近一天；不称为“连续回调天数”。
- 不用虚拟流通股本估算换手率；没有可靠历史股本时不提供该条件。
- 不移植由价量公式生成却冠以“AI 置信度”或“题材阶段”的字段。
- 价格条件使用本项目因果复权信号价；成交量、成交额使用来源原值。
