# 市场行业与个股的回踩蓄势轮动方法

这是一套待验证的第二版方法。第一版完整体系及四个主区间对照均亏损，不能据此宣称已经实现小亏大赚。第二版保留市场、行业、组合和退出的完整流程，优先检验入场前是否需要真实的蓄势过程。

主评价区间仍为2024年9月24日至2026年10月15日，连续50万元账户。此前的弱市只作压力对照，不要求获利。最新本地共同截止日为10月15日，缺少10月16日。

| 顺序 | 方法 | 这一层要回答的问题 |
| --- | --- | --- |
| 市场 | 沪深成交额、量能延续、双综指趋势和股票上涨广度共同判断，沿用第一版固定规则。 | 资金和趋势是否支持新增风险？ |
| 主线 | 使用当时已公布的行业成员，检查相对宽基强弱、内部上涨广度和成交参与度，连续确认后选最多三个方向。 | 强势是否形成行业共振和延续？ |
| 角色 | 领涨股须在五个交易日前和当前均已成为行业领涨成员；补涨股须有五日前已确认、目前仍健康的不同先行股。 | 谁已带队，谁具有可观察的跟随关系？ |
| 准备 | 前五日与再前五日相比价格区间收缩；近五日量能收缩、趋势保持，并至少一次回踩20日均线。 | 入场前是否经历了整理，而非只有一个强势数值？ |
| 触发 | 首次收盘突破此前五日高点，成交额重新超过此前20日均额；领涨与补涨都必须经过上述准备。 | 新需求是否在整理后重新出现？ |
| 风险 | 使用真实的前五日低点作失效位。信号价至该低点的距离至少容纳一个正常波动单位，同时不超过5%；次日开盘价变化后再检查一次。 | 入场位置与正常波动、真实支撑是否相容？ |
| 组合 | 最多五只，新股风险预算不超过权益1%，单股新增仓位不超过20%，同一行业不超过40%；先扣现金与费用，不预支卖出资金。 | 即使连续失败，账户是否仍有承受和参与后续机会的能力？ |
| 持有与轮动 | 沿用固定的个股止损、结构失效、市场与行业风险退出，以及波动跟踪保护；新行业必须重新确认，旧行业每天排名下降不直接触发换仓。 | 失败能否退出，趋势盈利能否保留，轮动是否有纪律？ |

“支撑距离不超过5%”只是入场约束。收盘确认、下一交易日尝试卖出的机制仍可能产生更大实际亏损，不能把这条规则当成亏损保证。已经单独测试过的波动上限并未解决问题，因此本轮检验的是有先后关系的整套准备过程。

同一行业内先看合格领涨，再看合格补涨；同类优先选择此前20日成交额更大的股票，再按行业内60日排名及股票代码排序。所有候选在收盘固定，每行业每天最多一只；无法成交不临时补选，已有持仓不加仓。历史行业归属未知时不补造资格。

第一版的领涨突破共44笔闭仓，平均亏损约7.21%，信号正常波动中位数约7.28%，初始失效距离中位数约为正常波动的0.70倍。这支持检验入场结构与风险距离的关系，但不能证明第二版会赚钱。行业退出分组净盈利，也不能据此断言保留或取消行业退出的效果。

验证将运行完整体系、取消市场入场限制、取消行业入场限制、取消补涨分支四个主区间账户，另加一个完整体系弱市账户。保留并复用第一版全部六个账户作为证据，行业流动性代表股对照无需重跑。比较整套方法的收益、回撤、扣费闭仓平均盈亏比、PF、亏损尾部、样本量、跨期表现和超额收益。信号或样本太少同样不能判定达标，也不在看到结果后临时放宽本版条件。

所有历史均属于已接触的开发样本。行业名单、原始价格和历史可交易性方面的既有资料限制继续保留。本轮不扩展分红转送研究，不进行实盘交易。机器可读规则见同目录的 `market-sector-stock-base-v2.json`；实现与独立验证完成前，本版没有可宣称的账户结果。
