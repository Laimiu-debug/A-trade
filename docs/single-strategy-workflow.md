# 策略回测与参数测试工作区

2026-10-13 按 final-trade 的实际操作链整理界面。默认工作区围绕同一次回测连续操作：配置、运行、查看结果、回填或保存参数。六阶段导航与独立“冻结与新时段验证”入口已收起；保存计算设置和限制验证期间改参由软件处理。

## 直接开始回测

“策略回测”在同一表单展示股票范围、日期、策略、选股条件、资金与交易规则。沿用全局行情来源，默认覆盖所选市场与板块的全部可读 A 股。选好策略和起止日期后点击“开始回测”，无需逐步切换配置页面。

基础资格检查上市时间、流动性及历史状态。趋势、结构、量能条件决定策略可以研究哪些股票；策略信号独立决定具体买卖。风格预设提供可解释的起点，未经过收益优化。交易成本、额外资格条件和完整生效参数按需展开。

提交前继续通过后台校验最终生效配置。编辑期间设置变化会使旧校验失效，不能提交过期参数。创建后同页展示任务进度与结果，点击“调整回测配置”可返回原设置；已有报告始终保留创建时参数。

日期支持完整键盘输入、粘贴 `20240131` 或 `2024/1/31`，离开输入框时统一为 `2024-01-31`。日历可直接切换年月。输入到一半或日历展开时，后台刷新保留当前输入框、光标和日历；草稿日期在切换页面及重新启动后保留。不存在的日期和颠倒的起止区间在提交前提示，不创建任务。

## 沿用当前配置测试参数

顶部“收益平原 · 参数测试”直接带入当前策略、日期、股票池和交易规则，不要求先完成一份固定参数回测。也可从已完成结果点击“用当前配置测试更多参数”。

每次选 1–3 个参数，每项 2–5 个不同值，总计最多 27 组。扫描项逐组替换，其他条件保持相同。切换回“策略回测”时沿用当前配置；组合与轮动另有独立高级草稿。

结果列出每组参数的收益、回撤、已完成买卖波段，以及附近参数是否稳定。提供四个直接操作：

- “回填到回测”：载入明确选中的参数，允许调整日期或重新回测。
- “保存参数”：将所选配置及原结果身份保存到“参数收藏”。
- “查看买卖记录”：使用原行情与原日期复现该点的逐日账户路径。
- “用其他日期验证”：在当前结果旁展开日期表单。

相同买卖和净值路径不重复计作稳定证据，未生效参数轴不能形成有效宽度。默认每组至少 3 个完整退出波段、3 个持仓交易日，最大回撤不超过 30%；附近参数还需通过盈利比例、绝对及相对波动、中位收益保留比例等条件。门槛在运行前固定，明细放在折叠区。没有稳定区域时仍保留真实结果，不自动采用最高收益点。

## 保存参数与验证其他日期

“参数收藏”保留已有保存方案，可载入为新的可编辑回测，也可查看原结果。旧内部冻结记录保持可读，无需用户迁移或重新输入配置。

验证表单只要求任务名称和另一段起止日期。日期必须严格晚于原回测结束日；打开表单不会写入参数记录。实际点击“开始验证”时，软件从已完成的原任务保存所选配置，再仅向后台提交保存身份和新日期。验证期间沿用原股票范围、策略、仓位、初始资金、费用及来源，不能由前端替换这些设置。

之前的行情只用于指标预热，验证账户重新从初始资金开始。重复使用同样参数和日期会标为重复计算；用不同设置重复利用原日期，不能当成新的验证证据。新的日期不等于策略有效，还需结合收益、回撤、实际交易和成交证据判断。

计算版本变化时旧参数仍可载入为新回测，但旧版本的方案不能直接继续原验证。普通日线缺少开盘量证据的成交保持近似诊断口径，不能认证总回报或系统平原。软件只能核对本工作区留存的使用记录，无法发现其他软件中已经查看过的行情。

## 高级研究与兼容

组合、轮动、滚动验证与全系统扫描收在“高级研究”。它们继续使用原有后台门控和独立草稿，不要求用户依次完成界面的研究阶段。普通回测和参数测试不会改写旧报告、删除保存参数或降低成交与数据隔离要求。

内部服务类型仍为 `singleBacktest`、`singlePlateau`、`frozenValidation`，保存方案接口仍为 `research.freeze/freezes`。这些内部名称不作为主界面操作概念。详细协议见 [系统研究说明](portfolio-system-research.md)。
