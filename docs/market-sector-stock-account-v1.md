# 第一版市场、行业与个股轮动方法

状态：完整规则已固定，尚未运行这套体系的市场账户。下列数字是第一版研究假设，将整套验证，不逐项扫描寻找最好阈值。详细契约见同目录的 `market-sector-stock-account-v1.json`。

主评价区间为2024-09-24至2026-10-15，连续50万元账户，不按年重置。弱市压力区间为2024-04-08至2024-09-23，不要求盈利；较早日期没有本轮已验证的行业名单，不冒充完整弱市覆盖。

| 决策层 | 第一版固定方法 |
| --- | --- |
| 市场是否允许进攻 | 沪深成交额代理至少1万亿元，5日均额至少为此前20日均额的80%；沪深两个综指均满足收盘及20日均线高于60日均线；研究股票池中超过一半位于60日均线之上，且观察覆盖率至少95%。 |
| 哪些行业成为主线 | 行业20日与60日表现均强于沪深300、超过一半成员站上60日均线、相对成交参与度不弱于大盘，连续确认3日。从符合条件的行业中选最多3个方向。 |
| 谁是领涨股 | 在当时已知的行业成员中，60日涨幅位于前20%且高于行业平均。领涨突破与强势回踩分别记录，不能混用事后解释。 |
| 怎样识别补涨 | 行业内5个交易日前已经出现不同的先行股，该先行股目前仍健康；候选中期向上、短期表现落后但不在最弱20%，自身首次突破此前5日高点并放量。 |
| 入场位置是否合适 | 股价不能过度偏离20日均线；先确定前10日低点与5%初始保护线中较高的失效位，再计算计划买价到失效位的距离。 |
| 怎样分配仓位 | 单股新开仓不超过20%，同一行业新增风险后不超过40%，最多5只股票；每笔计划价格风险不超过收盘权益的1%，同时受现金、费用、交易单位和成交容量限制。 |
| 怎样处理轮动 | 原行业持续转弱才触发行业退出；新行业必须独立确认才能分配现金。每天排名变化本身不触发卖出，补涨只在已形成先行关系的行业内部寻找。 |
| 怎样处理失败与大盈利 | 失效位、连续行业退潮、连续市场转弱负责退出风险；盈利持仓沿用已经审计的3倍过去20日归一真实波幅跟踪保护，不设固定止盈上限。 |

成交参与度使用同一观察成员的5日均成交额相对前20日均额，再除以大盘相同口径的量能变化，是活跃度代理。行业强弱使用当日已知成员及其过去价格，不能称为过去已经可交易的完整行业指数。

领涨突破、强势回踩和补涨有固定优先顺序。每个获准行业每天最多产生一个新候选，先排行业、再排个股，留存被拒绝和未成交原因。次日不因某只无法成交就补选原排序之外的股票。

全部判断与预算在T日收盘形成，T+1开盘只尝试一次。开盘越过失效位或高开超过事先规定的波动距离则放弃；实际风险、现金或容量不足只能减少原计划数量。价格跳空、跌停、费用等仍可能使实际亏损超过计划，不把止损线当成保证。

20%与40%是新增风险的约束。已有持仓上涨超过这些比例时，停止继续增加相应敞口，不因上涨超限本身强制止盈。卖出受阻仍保留退出指令，不能因为市场后来回暖就取消。

历史行业名单从公布后的交易日起启用。最新名单中缺失的股票保持归属未知，不用旧名单补回新开仓资格；已有持仓的个股风险退出继续执行。行业名单更换时重新建立确认和先行关系，不能把后来归属用于以前的选股。

验证时保留5个主区间账户：完整体系、只取消市场入场限制、只取消行业强度入场限制、只取消补涨入场分支，以及同样优选行业但买入行业内流动性代表股的对照账户。共同的风险退出和资金限制保持一致，因此差值用于检查这些入场环节的作用，不直接相加作因果归因。

再运行完整体系的弱市压力账户。所有账户同时检查扣费闭仓盈亏比与PF、完整净值、宽基及行业代表股对照、回撤、亏损尾部、资金暴露、换手、跨年表现和盈利集中度。保留全部失败结果。高盈亏比或某一年盈利都不能单独认定整套体系达标。
