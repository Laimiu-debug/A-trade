# finaltrade 前端交互核对与 A-trade 改造规格

核对日期：2026-10-13。参考的是本机 `G:/CODE/Final trade` 的当前工作区，Git 基准为 `2a00ffe7c50b5f023a5db9f1c09ace1683eb1912`；该工作区存在其他任务的未提交修改。本次只读参考源码，另起独立端口加载其真实 React 组件和项目自带 MSW 演示数据，未修改参考项目业务文件，未连接真实行情服务或交易账户。

本文件区分三件事：参考项目实际有什么交互、A-trade 当前做到了什么、后续具体需要补什么。以下改造项是规格，不能据此宣称 A-trade 页面已经实现。

## 1. 需要学习的是完整操作链

finaltrade 的分工是：

1. **策略中心**统一编辑策略参数、管理策略预设，其他业务页选择策略并使用同一份当前参数。
2. **选股漏斗**加载输入池，逐层配置、运行、查看股票，也支持一键运行与独立人工终选。
3. **待买信号**按指定范围、日期和策略生成信号，查看触发理由与 K 线，再接到待买回测或交易草稿。
4. **策略回测**配置区间和交易规则，运行后同页看进度、历史、指标、资金曲线和逐日操作。
5. **收益平原**使用当前回测配置作为基础，扫描变化参数，同页挑点、看交易、回填、收藏并继续回测。

收益平原在 `BacktestPage.tsx` 内，是回测配置下面的独立可折叠模块，并非要求用户经过多个认证阶段的向导。普通回测与平原各有独立任务状态和历史记录。选中历史结果、回填编辑设置、保存参数、重新计算是不同操作。

## 2. 选股漏斗：按钮、作用与页面内容

源码：`frontend/src/pages/screener/ScreenerPage.tsx`。

### 2.1 页面上能看到什么

- 板块、严格/宽松模式、筛选日期、所选策略、筛选结果所属的运行身份与数据状态。
- 输入池、第 1–4 步通过池、终选池、观察池，共七个股票池卡片。
- 每张卡的股票数量、当前配置摘要、是否已运行、是否能查看/导出，以及当前查看的是哪一池。
- 快捷名称/代码搜索与可拖动股票卡；股票池表格、当前筛选后数量、全池数量和分页位置。
- 表格可显示代码、名称、收盘价、涨跌额/幅、窗口涨幅、换手、成交额、振幅、回撤、回调天数、趋势、阶段、走势状态、评分、AI 置信度、题材阶段。
- 参数变更后旧输入池的提示；数据降级提示；手工加入的股票带明确标签。

### 2.2 完整按钮与动作清单

| 位置 / 按钮或操作 | 实际作用 | 操作后看到什么 |
| --- | --- | --- |
| 加载输入池 | 校验条件，调用筛选服务，再读取对应运行快照 | 输入数量、输入股票表、运行身份；观察池也可按规则生成 |
| 输入池：重新加载输入池 | 按当前输入条件重新获取数据 | 更新输入池与筛选运行身份 |
| 快速一键运行（可选） | 服务重新计算完整四步结果 | 各层数量与最终第 4 步列表；更新运行身份 |
| 运行第 1 步 | 更新服务快照，执行第一层筛选 | 第 1 步数量、股票表；下游未运行状态明确 |
| 运行第 2/3/4 步 | 按已运行前一层逐步筛选；不能越过尚未执行的步骤 | 对应池数量、股票表；重跑上游会使下游重新计算或失效 |
| 每步设置齿轮 | 在当前卡旁展开该步配置 | 参数、单位、规则和条件摘要；不离开漏斗页面 |
| 点击股票池卡片 | 切换下面正在查看的池 | 列表、数量、当前池名称、可操作按钮随之变化 |
| 每池导出 / 导出当前池 | 下拉选择 CSV、Excel、PDF | 导出所选池的数据；空池不可导出 |
| 清空终选池 | 清空人工终选列表，必要时切回可用自动池 | 终选数量归零；自动筛选池不被重算 |
| 观察池设置 | 设置自动观察条件，或选用其支持的策略筛选方式 | 观察池规则摘要、数量和股票列表 |
| 观察池清空 | 清空当前观察列表 | 观察数量归零；它仍是独立于四步漏斗的池 |
| 快捷搜索 + 拖动加票 | 搜索已加载股票，将卡片/表格行拖入允许的目标池 | 目标池增加股票，手工标签保留；重复股票不会重复加入 |
| 股票行：加入下一池 | 明确人工放行一只股票 | 进入下一个池；下游阶段按依赖关系失效 |
| 股票行：看图标注 | 保存漏斗界面状态，携带股票进入图表 | 对应股票 K 线/标注页面；返回可继续原池操作 |
| 股票行：加入待买单 | 创建或更新带来源、信号日期与参考价格的待买草稿 | 草稿反馈；不是直接成交 |
| 前往策略中心 | 打开统一策略参数编辑页 | 当前策略的参数与预设 |
| 表头设置 | 勾选显示列，调整列顺序 | 当前表格立即采用列设置 |
| 表头设置：上移、下移、重置默认列 | 调整或恢复列布局 | 排列与列显示状态更新 |
| 表头列名排序 | 按对应指标升/降序排列 | 排序标记、股票次序；保留自定义顺序模式 |
| 表头筛选：应用、重置 | 应用名称/代码或分类条件，或清除对应条件 | 筛选后数量、列表与分页变化 |
| 重置表头筛选/排序 | 清除全部表头筛选，并回到默认自定义排序 | 恢复当前池原来的查看范围 |
| 表内拖动重排、分页/每页条数 | 调整人工顺序或查看整池其他部分 | 当前排序、页码与总量清晰可见 |

### 2.3 每一层的配置内容

| 层 | 参考项目配置 |
| --- | --- |
| 第 1 步 | 涨幅窗口、排名起止、20 日换手/成交额/振幅下限 |
| 第 2 步 | 回撤范围、回调天数、均线排列持续时间、偏离 MA20、是否必须高于 MA20、是否允许 B 类趋势 |
| 第 3 步 | 成交量斜率、涨跌量比、回调量比、放量冲顶/量价背离/长上影等风险容许项、降级容许项 |
| 第 4 步 | 最终数量、AI 置信度、允许的题材阶段、降级容许项 |
| 观察池 | 自动观察条件及其单独的筛选方式，不等同于第 4 步或人工终选池 |

**源码核对后的限制：**该版本第 2–4 步的逐步运行会在前端使用当前名单计算；人工加入也是前端池状态。服务的运行身份与当前人工名单不能直接当作同一份历史规则。A-trade 应借鉴卡片及操作连贯性，但必须明确记录自动规则、人工名单与回测真正采用的范围。也不能把当前终选股票直接填入过去多年回测而声称是历史逐日选股。

## 3. 策略中心与策略运行

### 3.1 策略中心

源码：`frontend/src/pages/strategy/StrategyCenterPage.tsx`，共享参数工具 `frontend/src/shared/utils/strategyParams.ts`。

页面展示策略名称/版本/能力，当前有效参数、参数类别与差异；支持最多四个策略并排对比。参数编辑按类型使用数值框、开关和枚举选择，不要求用户自行输入参数对象。

| 按钮 / 操作 | 实际作用 |
| --- | --- |
| 策略选择 | 切换当前编辑策略，读取该策略当前共享参数 |
| 切换编辑 | 从对比卡将所选策略设为当前编辑对象 |
| 仅看差异参数、参数类别 | 过滤对比视图；不改变策略计算参数 |
| 保存视图、应用视图、删除视图 | 保存/恢复/删除对比策略、差异开关与类别筛选 |
| 导出视图、导入视图 | 将对比视图预设导出为 JSON 或从文件恢复 |
| 复制分享码、复制分享链接 | 将当前对比视图转成可复用内容 |
| 应用分享码、粘贴并应用 | 从分享内容恢复对比视图 |
| 参数数值框 / 开关 / 枚举 | 编辑当前策略参数，自动同步到业务页 |
| 保存预设、应用预设、删除预设 | 管理当前策略的具名参数模板；与对比视图预设分开 |
| 选股漏斗、待买信号、策略回测、事件判别链接 | 带着统一的当前策略配置进入具体业务流程 |

它并不在“策略中心”直接启动历史资金回测。A-trade 应将**策略定义、当前编辑参数、具名预设、已运行任务参数快照**明确区分；修改模板不能改变旧报告。

### 3.2 待买信号 / 策略运行

源码：`frontend/src/pages/signals/SignalsPage.tsx`。

这是单个日期的策略扫描与信号展示。条件改变会触发查询，也有明确的“手动刷新（重算）”。可选趋势池/全市场、趋势池阶段、来源身份、板块、日期、策略、窗口、评分、事件与信号年龄等条件。

页面显示有效、临期、失效、今日触发、B 类主信号、源候选数量；显示生成时间、缓存/重算、降级情况、各股票触发日期、信号/事件、有效期、评分与原因。

| 按钮 | 实际作用 / 后续内容 |
| --- | --- |
| 从选股池缓存绑定 | 从本机漏斗缓存读取来源身份与板块 |
| 绑定最新筛选任务 | 查询服务最新筛选快照并建立关联 |
| 去选股池、前往策略中心 | 修正来源或策略参数后回到扫描 |
| 展开说明、收起说明 | 展示当前扫描模式与使用说明 |
| 展开/收起股票行 | 展示事件序列、风险事件、触发理由、结构/趋势/阶段等分项评分 |
| 手动刷新（重算） | 明确要求重算，区别于读取缓存 |
| 股票行：查看 K 线 | 携带当前策略、日期、信号范围与筛选上下文查看股票图表 |
| 股票行：加入待买单 | 使用当前快捷数量及信号日期创建/更新草稿 |
| 股票行：去交易页 | 预填股票、方向、数量与信号日期，之后由交易页处理 |
| 一键生成 ETF 回测 | 将当前有效筛选信号及各自日期作为组成项创建待买组合回测 |
| 区间生成 ETF 回测 | 展开日期区间设置，按同一来源规则逐日重算信号并批量生成 |
| 区间弹窗：开始生成、取消 | 启动生成并显示进度，或取消当前配置操作 |

这些信号操作、组合回测、历史资金回测是不同产品动作，不能用“配置回测”一个按钮代替全部含义。

## 4. 策略回测：配置、运行、历史与结果

源码：`frontend/src/pages/backtest/BacktestPage.tsx`，普通任务状态 `frontend/src/state/backtestTaskStore.ts`。

### 4.1 配置区

配置包括趋势池/全市场、来源筛选、趋势池阶段、每日/每周/持仓触发滚动、策略、区间、信号窗口和最低评分、入/离场事件、初始资金、单笔仓位、最多持仓/股票数量、止损/止盈/移动退出、最长持有、费用、信号优先级、T+1、延迟入场与失效保护、计算路径、高级分析等。

策略能力不支持的项会禁用并解释原因。策略参数和预设只在策略中心维护。本页选择策略并带入当前参数。高级分析的计算成本与附加结果被明确说明。

### 4.2 按钮及任务行为

| 位置 / 按钮 | 作用 |
| --- | --- |
| 带入最新筛选 | 把服务最新筛选身份与规则上下文带进配置 |
| 前往策略中心 | 修改策略的统一参数/模板 |
| 开始回测 | 提交当前完整配置；生成新任务，同页显示进度与结果 |
| 暂停、继续、停止 | 控制选中的未完成任务；按任务状态显示对应动作 |
| 选择回测任务 | 切换当前查看对象，不代表自动回填编辑配置 |
| 最近任务进度：标题/展开箭头 | 展开/收起当前任务的百分比、当前日期、处理日期数、阶段耗时与告警 |
| 历史任务列表：标题/展开箭头 | 同页展开普通回测历史，而非进入独立队列才能找结果 |
| 历史行：查看 | 加载该任务状态/结果供浏览 |
| 历史行：回填 | 将该任务的完整运行配置还原到编辑表单 |
| 历史行：保存 | 把完整参数上下文保存到收藏库 |
| 历史行：导出 | 导出其交易记录，支持 Excel、CSV、HTML |
| 历史行：暂停、继续、停止 | 控制该行任务；不依赖当前查看的是不是该任务 |
| 历史行：删除 | 在允许的任务状态下删除对应历史记录 |
| 列表排序、分页、每页数量 | 查看历史及其时间、策略、区间、参数摘要、收益、回撤与状态 |

运行不会把配置区替换成另一套页面。普通回测与平原独立保存所选任务和后台运行状态，切换页面不等同于停止任务。

### 4.3 结果中能看到什么、还能做什么

- 执行路径、策略快照；成交数、胜率、收益、回撤、候选和跳过信号、成交率与并发持仓。
- 若报告包含相应数据，再显示 Sharpe/Sortino/Calmar/期望收益、稳定性、市场状态、蒙特卡洛、Walk-forward 各折结果。
- 资金曲线、回撤曲线；点击曲线点或选择交易日查看当日买入、卖出、持仓及次日操作计划。
- **前一天、后一天**按实际曲线交易日切换，不按自然日随意跳转。
- 逐日持仓显示股票、数量、价格、盈亏和仓位，股票可进入相应图表。
- 末日尚未执行的信号单独展示，不算成已经成交或已实现收益。
- 交易明细及排序/分页；**导出交易明细**可选 Excel、CSV、HTML。
- 收益构成可切换**饼图、柱状图、方块图**；缺少数据时显示原因。
- **运行说明**可展开/收起，保留实际计算提示。

**不能照搬的一处展示逻辑：**该工作区部分历史日“计划卖出”是从后来闭合的交易记录的 `exit_date` 与 `exit_reason` 推导，不等同于当天确实形成的计划。A-trade 应使用引擎当日留存的决策与队列，不能在历史日面板展示后来才知道的退出事件。

## 5. 收益平原：同一配置下的扫描、选择与复核

源码：同一个 `BacktestPage.tsx`；独立任务状态 `frontend/src/state/backtestPlateauTaskStore.ts`。

### 5.1 配置与进度

扫描沿用当前回测的完整基础配置。页面提供采样方式（拉丁超立方/网格）、评估点数上限、随机种子和参数候选列表；空列表沿用当前表单固定值。列表涉及窗口、评分、止损/止盈/移动退出、减仓、持仓数、仓位、最大股票数和同日 TopK。

| 按钮 / 操作 | 实际作用 |
| --- | --- |
| 收益平原参数与进度：标题/箭头 | 在回测同页展开/收起扫描配置与历史 |
| 开始平原扫描 | 将基础回测配置与变化参数一起提交为独立扫描任务 |
| 暂停平原任务、继续平原任务、停止平原任务 | 控制当前选中的平原任务 |
| 选择平原任务 | 切换该类任务的查看对象；不混用普通回测所选任务 |
| 平原历史行：查看、暂停、继续、停止、删除 | 加载或控制对应历史任务，按状态显示动作 |
| 平原历史行：导出 | Excel、HTML、ftbt；ftbt 可包含全部参数组合交易记录 |
| 回填推荐参数、保存推荐参数 | 将推荐区域代表点回填编辑区或存为收藏 |
| 选择第 N 名、回填第 N 名、保存第 N 名 | 对明确选中的排名点操作；不是每次都自动选最高收益 |
| 保存候选参数 | 将候选集中明确选中的点存为收藏 |

页面分别显示总组合数、实际评估数、进度、状态、推荐点与峰值点，避免把“已经评估几组”“一共有几组”“哪组最高”混在一起。

### 5.2 平原结果与选点

| 区块 / 操作 | 实际内容及作用 |
| --- | --- |
| 自动识别区域 | 区域分、点数、中心收益/回撤、邻域波动、参数范围；存在时展示样本外/滚动验证信息 |
| 回填区域中心、保存区域中心 | 对该区域具体代表点操作 |
| Top 30 平原分可视化 | 对比排名点的稳定性分数 |
| 参数相关性 | 展示参数与原始评分、收益、胜率的关系；样本不足时说明不可用 |
| 热力图横轴、纵轴、颜色指标 | 选择参数投影及平原分、局部分、单点质分、原始分或收益等显示指标 |
| 显示方块值、列内峰值线开关 | 控制图上标签和参考线；参考线不代表可执行的参数路径 |
| 热力图单击 | 选中并回填该格代表点；显示格子的聚合值和回填点的规则必须解释清楚 |
| 框选、加入候选 | 将明确框选格子对应的参数点去重加入候选集 |
| 清空框选、候选选择、回填候选、清空候选 | 管理临时候选集合；与长期收藏分开 |
| 平原表格排序、恢复默认排序 | 按具体指标查看参数点，并记住排序 |
| 每组：回填、保存 | 回填完整运行配置或长期收藏该点；失败点禁用 |
| 每组：查看交易记录 | 优先读取已保存单点明细；缺少时提示后临时重算，并弹出曲线、实际指标与交易表 |
| 交易记录弹窗：回填参数、关闭 | 将该组参数带回编辑区，或回到原扫描结果继续比较 |
| 每组：导出交易记录 | 导出该点的完整交易记录 Excel |
| 空图/失败点/无区域提示 | 说明不能展示二维图、计算失败或没有区域的具体原因 |

**A-trade 的约束：**借鉴这里的可操作结果页，同时保留已修复的稳定区门槛、参数可辨识性、未知数据、成交证据和未来数据隔离。高收益单点、无成交点、未合格点不得自动包装成“推荐平原”。多个隐藏维度落在同一热图格时必须展示聚合口径，明确选中的完整参数，不能画出不存在的可执行连通区域。

## 8. 页面改造后的具体布局和行为

### 8.1 选股漏斗页

顶部：行情来源、筛选日期、市场/板块、当前策略；主操作为“加载输入池”和“一键运行”。

中部：按数据依赖排列的池卡片。每卡固定显示数量/状态/条件摘要，带“运行本层、设置、查看、导出”。选择卡片只切换下面列表，不重建整页。

底部：当前池名称、搜索、排序/列设置、完整分页表、每股“查看 K 线”。人工选择需保存来源标签，有单独的“加入终选”与“撤回”。“用这些规则运行策略/回测”清楚展示将采用的范围。

参数变更后明确标示待重算或旧结果；运行上游只重算受影响下游。未知资格与被剔除原因持续可查。当前股票快照与历史逐日规则不得混淆。

### 8.2 策略运行与策略配置

策略配置：一处编辑实际注册策略的参数，保存用户模板，显示定义/单位/范围。业务页显示当前策略与模板摘要，修改入口回到同一编辑器。

策略运行：在所选历史日期按真实来源与规则计算候选、评分、入场条件。先给数量及状态，再给可排序的股票列表和逐项原因，支持带上下文看图并继续回测。没有数据或不支持的维度直接说明。

### 8.3 回测页

一个页面依次放：**回测配置 → 开始/暂停/继续/停止 → 实际进度 → 普通历史 → 当前结果**。配置可收起但运行不自动丢掉编辑区。结果查看与草稿编辑分别存储。

历史行固定展示名称、策略、区间、核心参数、收益、回撤、状态、操作。查看不改草稿；回填才替换草稿；重新开始才生成新任务。运行中可继续查看其他已完成任务。

结果以指标、资金/回撤曲线、交易日选择、当日买卖/持仓/实际次日计划、交易明细为核心。重要操作跟在相关内容附近；完整导出、参数收藏与诊断细节按需展开。

### 8.4 平原页/回测中的平原模块

顶部始终显示沿用的基础配置摘要，并有“修改回测配置”。只编辑变化参数和服务支持的扫描方式，提交前给组合数与固定条件。

结果以**实际扫描进度 → 平原历史 → 区域摘要 → 热图/参数表 → 当前选中点 → 候选/收藏**排列。选择点必须立即显示完整参数与关键指标；“查看交易记录、回填回测、保存参数、导出”作用明确，操作后能继续原来的比较。

没有合格区域时显示“未找到稳定区域”，保留诊断点供查看，不自动推荐尖峰。其他日期验证留在结果的可选操作中，日期隔离及重复使用标记由服务处理。

## 9. 实施顺序与验收

1. **先改状态与工作区骨架**：编辑草稿与结果分离，普通/平原任务分离，同页历史及任务控制。接现有真实服务，避免继续增加假入口。
2. **补漏斗实际操作**：分层设置、分层运行、来源规则、终选/观察、表格交互与上下文衔接。必要的服务扩展同步落地。
3. **统一策略配置并补单日运行**：共享模板、真实日期扫描、结果解释与看图/回测衔接。
4. **补平原选点闭环**：排序、区域/投影、候选集、原始行情单点明细、完整回填、收藏及导出。
5. **补报告与长期管理**：实际输出格式、报告包导入校验、收藏管理、跨进程恢复。

每项需要通过真实桌面验证：按钮实际调用正确任务/参数；上游条件变化使下游失效；回填完整上下文；看历史不覆盖草稿；输入/焦点/滚动在后台刷新中稳定；切页与重开能恢复；导出包含全量而不是当前分页；报告、失败、未知与未认证状态准确。此前修复的数据隔离、成交模拟和稳定区判断继续执行。
