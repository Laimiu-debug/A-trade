## 参考界面的输入项

| 输入项 | 参考含义及后续处理 |
| --- | --- |
| 股票代码、名称 | 选择股票。最终遵循全局规则：代码显示六位数字且同时显示名称，例如长江电力（600900）。 |
| 当期盈利（亿元） | 截图采用手工输入；用户已确认软件自动获取财务数据，采用最近 12 个月归母净利润（TTM）。 |
| 预期年增速（%） | 作为估值输入参考；如何与复合增速系数关联、增长年限和取值依据后续讨论。 |
| 行业基准 PE | 提供行业参考取值；具体分类、基准数据及校准方法后续研究。 |
| 大盘指数点位 | 作为大盘水位的输入参考；所用指数及点位到系数的映射待明确。 |
| 情绪溢价系数 | 作为情绪估值的系数输入；定义、生成方式及调整规则待研究。 |
| 实际市值（亿元，可选） | 用于与模型估算结果对照；自动获取方式及是否作为筛选必需字段后续讨论。 |

## 后续研究目标

- 软件架构建立后，进一步分析并完善该估值法。
