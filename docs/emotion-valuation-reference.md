# 情绪估值参考记录

状态（2026-10-11）：情绪估值默认展示自动同行估值观察，读取真实数据后直接给出相对位置与依据，无需先填写系数。下方“数据依据 / 手动情景”切换保留原有乘数模型。软件取得公开财报构造归母净利润 TTM，显示来源市值、报告期、公告日期；大盘水位由已配置来源的上证指数收盘点位单独计算。财务来源、计算口径、缓存及估值降级见 [公开资讯、财务与行业资金](market-information.md)。

本文保留最初截图内容及用户目标。已核对本机 FINAL-TRADE 中的公式实现，截图数值仅作历史示例，不代表当前数据；当前功能不将这些示例值写入实际财务，也不自动采用截图中的行业 PE 预设。

## 当前实现与边界

### 默认自动观察

- 搜索框支持股票名称、代码和通达信拼音首字母（如长江电力 / 600900 / CJDL），页内候选可直接点击或用方向键、回车选择，随后自动分析；顶部全局搜索也使用真实证券目录。
- 使用同一数据日、同一行业样本中的个股 PE(TTM)，与同行正 PE 的中位数、P25、P75 对照；至少 3 个有效样本。
- 个股 PE 小于 P25 为低于多数同行，大于 P75 为高于多数同行，两端及区间内部为同行常见区间。
- 相对中位数差距 = 个股 PE ÷ 同行中位 PE − 1，显示折价或溢价。该差距不是预期涨幅；不将低 PE 直接解释成低估或买入信号。
- 行业历史位置仅将行业整体 PE 与其自身历史分布比较，不将个股 PE 与行业整体历史混为同一口径。
- 来源日期始终可见；旧缓存、失败、非正 PE、样本不足和身份冲突不生成最新结论。缺少财务或市值不会伪造数据，也不影响独立有效的同日同行 PE 比较。
- 自动同行对照不叠加水位、增长或情绪系数，避免把已包含当前市场环境的同行 PE 再乘一次市场水位。

### 大盘水位

`market.finance.context` 读取配置来源中的上证指数最近可信收盘日线，返回点位、日期和来源，使用旧项目明确的模型约定：

**水位系数 = max(0.5, 上证指数收盘点位 ÷ 3000)**。

3000 点对应 1，4090 点对应约 1.3633；0.5 是模型下限。3000 是本模型归一锚点，并非交易所定义的估值中枢。指数缺失不回填 1；旧日线明确标注。水位本身不能证明市场便宜或昂贵，仅供手动情景采用。指数日期独立于个股同行估值日期，不假定两者同步。

### 手动情景

手动页按以下关系展示结果，金额内部统一为元，界面按金额大小换算：

- 情景底座 = 归母净利润 TTM × 盈利增长系数 × 基准 PE × 大盘水位系数。
- 情景市值 = 情景底座 × 情绪溢价系数。
- 模型隐含溢价 = 实际总市值 ÷ 情景底座。

TTM 缺失、为零或亏损时不使用此乘数模型。系数必须大于零；系数 1 表示中性情景。
基准 PE 可自行填写或点击采用同行参考；水位可点击采用已读取的指数计算值，不覆盖已有手动输入。
盈利增长系数 1.05 仅表示将 TTM 盈利上调 5%，不自动预测增长年限或假定多年复合。当前没有把行业名称映射成未经校准的固定倍数。
来源市值不可用时，可手填当次情景的对照值，不改写来源记录。
日收盘市值明确显示实际交易日；缓存保留原日期，不冒充实时值。

跨行业页先整理完整最新 A 股财报目录，为全部候选构造 TTM，并读取同日收盘市值目录。
名称、代码、行业、正盈利、实际市值低于情景底座、市值／TTM 上限及列排序都在完整候选中执行，再分页展示；
页面同时说明可比覆盖和缺失数据，来源分页未完成时不发布部分结果。每家公司保留自己的报告期，统一情景系数仅供比较，不代表
已测得行业公允价值。当前功能不执行策略、回测或自动买卖，参数校准仍需后续研究。

## 参考界面的输入项

| 输入项 | 参考含义及后续处理 |
| --- | --- |
| 股票代码、名称 | 选择股票。最终遵循全局规则：代码显示六位数字且同时显示名称，例如长江电力（600900）。 |
| 当期盈利（亿元） | 截图采用手工输入；用户已确认软件自动获取财务数据，采用最近 12 个月归母净利润（TTM）。 |
| 预期年增速（%） | 旧代码为 1 + 增速 / 100，并未多年复合；当前改称盈利增长系数，保留明确假设。 |
| 行业基准 PE | 提供行业参考取值；具体分类、基准数据及校准方法后续研究。 |
| 大盘指数点位 | 已核对旧代码 max(0.5, 点位 / 3000)，当前从配置来源读取上证指数收盘点位并展示计算依据。 |
| 情绪溢价系数 | 作为情绪估值的系数输入；定义、生成方式及调整规则待研究。 |
| 实际市值（亿元，可选） | 原图用于与模型估算结果对照；当前从公开来源获取，缺失时允许手填单股情景对照值。 |

## 后续研究目标

- 在现有情景计算基础上，进一步分析并校准该估值法。
- 从当前财报分页比较扩展到经过验证的跨行业批量研究，寻找模型判断下可能低估的候选股票。
- 研究行业基准、增长假设、大盘环境和情绪系数对估算结果的影响，并明确“严重低估”的判断口径。
- 研究行业参数、全量排序、财报历史可用性和验证方法；当前行业仅采用来源分类，不隐含正式的估值分组。
