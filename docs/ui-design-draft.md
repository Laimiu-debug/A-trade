# A-trade 前端 UI 设计初稿

版本 V0.5，2026-10-11。面向个人使用的 Windows 桌面应用，默认采用用户已选定的浅色主题。本稿覆盖全部已提出功能的页面布局、交互、组件、设计令牌及动画方向。本版补充应用主标识、全软件按钮与功能入口图标，沿用 V0.4 波段徽章、V0.3 连续通行证轨道及 V0.2 多任务设计；参数表单、阶段分组框及常驻详情卡继续移出通行证主区。

页面以曲线、操作记录和研究依据为主体，账户总览顶部通过通行证展示长期目标及连续阶段成就。通行证按账户整体收益推进，目标收益率和阶段数由用户设置；30% 和 70 阶段只是示例。用户记录在本机保存并自动备份；多个研究任务各自支持进度、暂停、继续、停止，以及退出或重启后从保存进度继续。具体业务判定和指标口径以 [需求记录](requirements.md) 为准。

设计交付包括本稿、[浅色设计令牌](design-tokens.md)、[整套图标设计及三张 V0.5 设计板](icon-design.md)、[V0.4 通行证轨道稿](design/pass-rail-v04.png)、V0.2 整体规范板及放大细节板。本稿覆盖 50 个页面与全局视图；V0.2 图中的 06 通行证和关联动效以新版修订为准。保留的 V0.1 页面图仅作早期风格参考。2026-10-11 用户已授权搭建 [HTML 预览](../preview/index.html)，交互和业务边界见 [预览说明](../preview/README.md)。

## 视觉方向

- 白色卡片和表格置于浅灰背景上，边界清楚，留白围绕信息分组安排。
- 蓝色用于导航、主操作、股票链接和当前研究曲线。行情正负方向采用红绿，同时保留正负号、文本与形状。
- 默认字号 14px，重要图表和数值优先于装饰。每屏主要动作通常一个，其余使用次按钮或菜单。
- 通行证以连续进度轨道和精致里程碑表达长期历程，滚轮可横向浏览；节点数量与收益目标来自账户数据配置，详细数值和关联持仓按需查看。
- 不同研究共享图表和记录结构。用户看到一条曲线后，能够找到对应日期、判断依据和操作记录。
- 保留浅色语义令牌结构供未来主题扩展，深色主题不作为本轮已完成的设计交付。
- 应用主标识、导航、所有按钮及状态图标专门设计并统一使用；详情页复用所属功能图标。50 个页面的对应关系见整套图标设计，常见操作保留易识别的符号和明确文字。

## 全局导航与工作区

### 主导航

| 一级模块 | 二级入口 |
| --- | --- |
| 账户与复盘 | 账户总览、交易管理、复盘统计、复盘分享；按完整业务职责组织，见下表。 |
| 市场与行情 | 市场总览、板块行情、个股行情、资讯。板块详情和个股详情通过列表进入。 |
| 策略与回测 | 策略中心、回测工作区、报告库。收益平原和研究对比是工作区内功能，结果和操作路径从研究进入。 |
| 分析工具 | 情绪估值、趋势龙头、板块资金动向、异动追踪、统一跟踪池。跨行业筛选归估值，连板梯队归趋势龙头，断板再涨停归异动追踪。 |
| 设置 | 系统设置。数据源、费率、规则、备份、外观和诊断在页内分类切换。 |

- 一级导航固定，点击模块展开或收起二级入口；点击入口后进入内容。宽窗口的子项统一缩进，窄窗口在模块旁展开带图标与名称的浮动菜单，选择后自动收起；点击外部或按 Escape 也可收起。详情视图选中对应的上级入口。
- 顶部全局栏提供股票及页面搜索、任务入口、数据状态入口和灵感闪记入口。任务入口常驻显示“运行 X · 排队 Y”，打开任务抽屉或完整任务中心；页面标题、区间与主操作位于内容区顶部。
- 底部状态栏显示行情截至日期、MCP 状态、本机保存状态和最近备份状态；点击后打开对应详情。
- 返回按钮是详情页固定操作，保留来源页面的筛选、已选项、排序、日期区间及滚动位置。外部首次进入个股页时提供明确的所属列表入口。
- 任务中心和数据状态属于全局入口，不形成额外的一级业务模块。资讯在工具首页可有快捷入口，使用同一个资讯页面。

### 按 final-trade 页面职责重整（2026-10-11）

参考用户指定的 final-trade 的实际路由、导航与页面内容；具体依据见 [参考分析](references/final-trade-page-structure.md)。原先将十五个视图搬到四组标签的方案被替换，以下四页各自承载完整流程。

| 侧栏入口 | 直接呈现的内容 | 页面内操作 |
| --- | --- | --- |
| 账户总览 | 里程碑、资产、收益、仓位和持仓 | 账户配置、资产快照抽屉、股票详情 |
| 交易管理 | 交易/资金流水、次日交易计划 | 记录成交、导入与对账、导出当前流水 |
| 复盘统计 | 收益与回撤双曲线、统计、笔记、操作与执行对照 | 每日/周期/灵感切换；跳转市场与次日计划 |
| 复盘分享 | 收益回顾卡片与复盘文字 | 编辑复盘、导出脱敏摘要 |

局部记录类型使用少量标签；账户管理、快照、导入不再独立成页。旧账户链接映射到新页面、相应区块或弹窗，A08/A09/A12 原有笔记键保留。进入股票后返回保留来源页面的记录类型、筛选与滚动位置。下文旧编号清单描述功能范围，不等同于侧栏入口。

### 桌面尺寸

基准画布为 1440×900，导航 224px、全局栏 56px、状态栏 28px、页面边距 24px。内容使用 12 列网格，常见主辅比例为 8∶4；研究配置栏约 288px，详情抽屉约 360px。

1024 至 1199px 宽度时折叠主导航和辅助区；1200 至 1439px 调整导航与列间距；宽窗可并排查看图表和依据。主要动作始终可达，表格可独立横向滚动。Windows 缩放与字体放大规则见设计令牌。

## 页面布局模板

下列模板只定义工作区排列，所有页面都使用相同全局外框。各页面表中的“右侧”在窄窗时变为详情抽屉或展开区域。

### 总览模板

用于账户总览、市场总览和每日工作台。内容从核心叙事或状态概览开始，再给出主曲线和待办，最后是明细。

```text
顶部专题：账户收益通行证 或 市场风格状态 或 当日复盘步骤

主图及联动子图，占约 8 列                         计划／依据，占约 4 列
持仓／候选／事件明细表
```

### 列表模板

用于流水、资讯、跟踪池、策略库和报告库。筛选固定在表格上方，已选范围清晰可见。

```text

```

### 研究模板

用于回测与收益平原。配置、运行状态和结果分区，配置较长时可以折叠，完整曲线拥有独立空间。


### 分析详情模板

用于个股、板块、研究结果和报告详情。先显示对象及来源，图表占主体，依据与事件可并排查看。


### 编辑与预览模板

用于复盘、交易计划和分享卡片。左侧填写与组织内容，右侧同步显示关联证据或导出预览。

设置使用模块内分类导航、中央配置和就近状态说明；首次引导使用步骤条，并展示每步的连接或保存结果。

## 全局交互

### 股票与返回

- 所有出现股票代码的组件必须同时显示股票名称，包括表格、标签、图例、提示、报告、分享预览和任务说明。示例写作“长江电力 600900”，不显示市场字母前缀。
- 股票代码点击进入唯一的个股日线与分析页。列表行的其他区域可打开行详情，两种操作具有明确边界。
- 从研究结果进入个股时，携带该研究的日期和记录位置；返回后继续停留在原研究和选中参数。
- 报告、卡片等导出预览仍展示名称与六位代码。导出的静态图片无法提供页内跳转，软件内的原始页面保留点击与返回能力。

### 选择与筛选

- 股票选择器统一提供搜索、主板／创业板／科创板等筛选、全选、清空及已选数量；具体完整上市板块分类另行确定。
- 初稿全选默认作用于当前筛选结果，明确显示“选择全部 N 项”；跨页选择保持已选状态，不以当前可见行数冒充总数。最终全选范围待用户确认。
- 非股票多选同样提供全选与半选。账户、主题等互斥单选不机械提供多选全选；需要汇总时提供“全部账户”等有效选项。上市板块筛选在非股票选择中的适用边界仍需确认。
- 更改筛选后显示当前结果中已选数量及筛选外已选数量，允许分别清空；不静默取消既有选择。
- 研究配置完成后显示股票数、策略数和预计参数组合数；规则有冲突时显示具体条件和处理入口。

### 曲线与记录

- 收益、盈亏、亏损、回撤、资产和仓位使用明确名称与单位；金额与百分比初稿分图或切换显示。
- 曲线支持悬停或键盘选择日期、缩放、拖动、重置、日期区间和图例选择。存在精确统计时以完整数据计算，显示抽样不改变结果口径。
- 主图、回撤图、成交量和记录使用同一日期定位；缩放后可查看区间统计，并可一键恢复全部时间。
- 点击买入、减仓、退出标记定位操作记录，区分晚间判断和下一交易日成交；点击记录反向定位图表。
- 风格转变以竖向标记和说明表达，保留识别日期与后续结果的区别。
- 图表右上方展示数据截至日期、口径和来源入口。长图可导出指定区间；导出内容和格式继续细化。

### 编辑与保存

- 笔记和复盘在编辑后短暂等待再自动保存，界面显示“正在保存”“已保存”或“保存失败”。未成功保存时保留编辑内容和重试入口。
- 金融流水、账户金额和规则调整使用显式保存或确认应用，先展示变更结果；导入先预览、检查重复与对账后提交。
- 参数配置未提交前可自由编辑；运行后修改配置形成新任务，已运行任务仍关联原配置。
- 数据刷新不覆盖正在编辑的手动内容。自动计算字段与人工修正字段在视觉和来源说明中区分。
- 普通导航不会清除编辑草稿；长研究任务不会阻止页面切换。

### 键盘与反馈

- Ctrl+K 打开全局搜索，Esc 关闭当前浮层并返回触发位置，Tab 顺序覆盖主要操作。
- 列表方向键移动，Enter 打开当前行详情；聚焦股票链接时 Enter 进入个股页。图表提供可聚焦日期游标和记录表作为替代查看方式。
- 快捷键在菜单中可见；输入框编辑时不触发页面快捷操作，避免与 Windows 常用快捷键冲突。
- 保存成功用短暂提示，失败保留原位置与原因；任务完成提示可进入结果，也可留在当前页面。

## 全部页面方案

### 账户总览布局细化

顶部通行证轨道约 180 至 224px 高，主区由标题、连续进度条、里程碑和简短滚动提示组成。删除右侧目标表单、下方阶段范围框、展开按钮排及固定阶段详情卡。目标收益率、阶段数和起算信息保存在账户数据配置中，主区不重复堆放这些参数。未建立通行证时提供进入账户数据配置的轻量入口。

主曲线区约占内容宽度三分之二，默认展示账户收益，下方独立展示回撤。右侧放次日计划和数据状态。持仓列表保留名称代码、数量、成本、当前价值、盈亏、计划状态及股票入口；较窄窗口将辅助区折叠为抽屉。

细长轨道连接里程碑，已完成部分以蓝色进度光带表现，未到达部分采用浅灰蓝。普通里程碑使用银边蓝色晶面与专属波浪折带图案，当前里程碑略放大并带局部光环，重要里程碑采用双层边框；两端渐隐提示轨道可以继续浏览。图案身份与业务状态分开，同一节点达成前后保持同一图案。六种图案为视觉主题示例，不限制用户设置的阶段数，具体造型和分布继续评审。

点亮动画仅在首次确认达标时出现。历史成就再次打开保持稳定；详细收益、时间及依据在悬停提示或点击后的详情中查看。单只股票的买卖不会单独点亮账户里程碑，滚动浏览也不会改变实际进度。

### 滚轮通行证布局与数据配置

```text
账户收益通行证                                  滚轮浏览历程
渐隐边缘 ── 已达成徽章 ══ 蓝色进度光带 ══ 当前徽章 ── 未来徽章 ── 渐隐边缘
                 小号序号或简短名称           当前
                    滚轮或拖动，浏览完整历程
```

轨道保持一条连续历程，不再采用“01–10、11–20”等分组框或章节页签。窄窗减少同时可见的里程碑数量，通过同一轨道继续浏览；节点很多时按可视范围加载，仍保持整体顺序。初次进入定位当前进度，再次返回恢复用户浏览位置。

- 鼠标位于轨道区域且存在可浏览内容时，滚轮可横向移动历程；触控板横向手势、拖动和键盘方向键提供同等操作。
- 到达轨道边界后允许页面继续滚动；鼠标移出后恢复普通页面滚动。Ctrl+滚轮等缩放操作不被通行证占用。
- 滚动只改变观看位置。查看未来节点不解锁里程碑，也不更新实际账户收益。
- 默认不展示常驻信息框；悬停或键盘聚焦仅显示简短数值与日期，点击可进入里程碑详情。主要视觉始终留给进度条和徽章。
- 拖动和连续输入即时跟随；滚轮结束后的短过渡平滑收尾，不强制逐级跳页。减少动态效果时直接定位。

全部阶段完成后在终点显示最终徽章，历史仍可滚动查看；新通行证在账户数据配置中建立，不显示超出总数的下一阶段。

| 配置或信息 | 初稿设计 |
| --- | --- |
| 关联账户 | 显示实盘／模拟标签；不同账户分别计算，互不混入成就。 |
| 每阶段目标收益率 | 在账户数据配置中输入，明确百分比单位；初稿采用统一阶段目标，逐阶段不同目标如需要再扩展。 |
| 阶段总数 | 在账户数据配置中设置正整数；主轨道根据实际数量生成和滚动，不在右侧放编辑表单。 |

| 调整目标 | 提交前显示将影响的当前及未来阶段。初稿保留已达成阶段当时的目标与记录，新配置另留版本，生效边界继续确认。 |
| 全程与本阶段进度 | 主区以连续进度条表达，精确完成数、当前账户收益及目标在按需提示和详情中查看，不将任务百分比与收益率混用。 |

节点区分已达成、进行中和未开始；记录不足、亏损或未达到目标时保留真实数值与原因。阶段结束、达标后回撤是否保留点亮、重新起算以及收益超出单阶段目标时是否连续过关，仍需确定。入金不能直接算成投资盈利，入出金调整、费用、已实现与浮动盈亏口径须先统一。

通行证目标服务于账户记录和回顾，不自动改变策略止盈止损或生成买卖动作；研究与交易管理的参数继续由对应配置确定。

### 收益平原布局细化

参数扫描区分策略参数、持仓数量和比例、止盈止损、减仓规则。每组参数可查看范围和约束；初稿先以二维热力图观察一个切片，其余维度通过固定值或筛选切换。

选择一个单元格后，下方显示该参数组合的收益、回撤及样本量，并能打开完整操作路径。寻找参数区间和后续验证区间采用不同标签及背景带；寻找区间的高收益不能作为验证结果显示。

稳定区间的判定规则及多指标权衡仍待研究，初稿显示“参数邻域”“候选区域”和实际指标，不自动赋予“最佳”“优质”之类未经定义的结论。

### 情绪估值布局细化

顶部始终显示股票名称与六位代码，以及行情和财务日期。输入区包含 TTM 归母净利润、预期年增速、行业基准 PE、大盘指数点位、情绪溢价系数和实际市值；TTM 默认由软件获取，其他项明确区分数据、假设和模型计算值。

行业 PE 预设以可选择的参考卡片呈现，保留用户截图中的六类参考，但标注其为待校准预设。结果区显示理论市值、基本面底座和隐含情绪溢价，并提供公式分解和来源入口。

曲线候选为实际市值与模型估值区间、TTM 盈利变化和估值偏离。预测假设与历史观测分开标注；财务不足或模型系数未定义时，展示对应缺口，不生成伪精确估值。公式及参考见 [情绪估值记录](emotion-valuation-reference.md)。

## 状态与恢复

### 多个回测任务同时运行

```text
任务中心        运行 X／上限    排队 Y    暂停 Z    失败 F
资源状态        计算占用／内存使用              自动分配／高级限额
搜索与状态筛选  全选当前结果  批量暂停／继续／停止  暂停队列调度
任务名称／对象    类型    阶段    进度    等待原因／优先级    操作
研究 A           回测    模拟    已完成／总量              暂停 停止
研究 B           参数扫描      已完成组合／总组合           展开子任务
研究 C           回测    排队    等待资源／队列位置         调整顺序
右侧：当前选中任务的配置、保存点、状态及结果入口
```

所有任务均可提交和查看，真正同时计算的数量受全局资源预算约束。自动分配为初稿默认，具体并发值通过本机实测确定；高级限额从任务中心就近调整，设置页面提供同一配置入口。资源数值尚未测得时显示“正在检测”，不得填入示意占用值。

- 每行有稳定的任务名称、对象摘要、提交时间、当前阶段、真实进度、耗时、最近保存点、优先级和可用控制。涉及股票时始终显示名称与六位代码；大量对象以“股票池名称 · N 只”概括，详情中完整展开。
- 研究工作区可打开多个标签，固定少量常用研究，其余通过列表切换。标签和任务生命周期分开：关闭标签仅关闭视图，停止必须使用明确的任务操作。
- 初稿按同优先级提交顺序并考虑资源需求调度，可手动提高排队任务优先级；不把队列位置当成精确等待时间。排队区显示等待计算额度、内存、数据准备或依赖任务等具体原因。
- 参数扫描以一个父任务汇总组合进度，按需展开子任务；子任务计入全局额度，避免多次平原研究各自占满机器。一个独立任务失败不会连带停止其他任务。
- 暂停或停止参数扫描父任务时，作用范围覆盖其待运行和运行中的子任务，并逐项等待保存生效；已完成组合保留。部分子任务失败时显示失败数量，父任务的完成与重试规则明确可见。
- 全选遵循当前筛选结果。批量操作先显示作用范围，并逐项反馈结果；对已完成任务不能继续或暂停。停止多个任务时明确列出数量及将保留的阶段结果。
- “暂停队列调度”阻止后续任务启动，已运行任务继续；“暂停全部活动任务”先暂停派发，再向选中运行任务发暂停请求。两者使用不同名称，不共用含糊的“全部暂停”按钮。
- 暂停实际生效并保存后释放计算额度；点击继续先进入队列，获得资源才显示运行。降低并发上限初稿先影响后续派发；如用户要立即回收资源，使用明确的暂停操作。
- 多个任务完成时使用合并通知及完成列表，避免连续弹窗。全局栏展示数量，不对不同类型任务的百分比求平均。可比较的同批研究另显示已完成任务数／总数。
- 退出和恢复以全部任务为范围，保存队列顺序、优先级、任务状态与保存点。重启后按用户选择和资源预算逐步继续；恢复失败单独标出，不挡住其他任务。
- 默认只持续绘制当前查看任务的曲线；其余任务保持数值进度与必要状态更新，切回时展示保存的结果，避免大量后台图表重复绘制。

任务数量较多时提供状态分页或虚拟列表，固定筛选与批量操作区。具体列表规模、资源估算、并发上限和响应性能属于后续实现验收内容，不由静态设计图证明。

- 暂停和继续针对同一任务；继续后可能先排队等待资源。停止结束任务，之后复用配置属于新任务。
- 停止操作初稿显示简短确认，说明已完成结果会保留、任务不再继续；“暂停并稍后继续”作为可选择的替代动作。是否每次确认可在评审时调整。
- 退出应用前保存一致状态；下次打开显示可恢复任务列表，用户选择继续，原任务的数据与策略版本保持不变。
- 点击窗口关闭按钮后是退出还是留在托盘，尚未确认。初稿提供“后台继续”和“保存进度并退出”两种清晰选项，默认行为后续确定。
- 不能确定总工作量时展示当前阶段和已完成数量；可计算时展示真实百分比。预计剩余时间仅作为有依据的估计，明确不是精确承诺。
- 进度不依赖页面是否打开。图表若展示阶段结果，标明数据截至日期和未完成区间，不把部分结果包装成完整研究。

## 核心使用路径

### 晚间复盘到次日操作

每日工作台 → 检查数据 → 查看市场风格与板块 → 复盘当前持仓 → 查看候选与研究 → 保存次日计划 → 次日关联成交及未执行原因 → 执行对照 → 每日和周期复盘。

每步都可查看来源和返回上一上下文。任务未完成时可继续查看账户；计划保存后仍区分计划意图与实际成交，组合仓位检查显示具体限制及需要处理的候选。

### 研究到收益平原

策略库 → 选择策略和股票 → 配置单策略或多策略研究 → 检查数据与条件 → 运行任务 → 查看曲线和路径 → 扫描参数 → 选择稳定区域候选 → 查看后续验证 → 保存报告。

参数单元格、结果、曲线、操作路径与报告关联同一次运行。用户切到个股页后返回，保留所选参数及日期。规则仍待定义时，页面保留配置说明，避免把初稿界面里的示例规则默认为最终算法。

### 行情工具持续跟踪

趋势龙头／资金／异动／连板工具 → 查看入选依据 → 加入统一跟踪池 → 查看后续事件 → 点击事件定位日线 → 关联研究或闪记 → 修改观察状态或归档。

重复加入同一股票合并到已有跟踪对象，同时保留本次来源和原因。断板后再涨停显示完整事件时间线，按时间顺序区分每次连续段，不将“四次涨停”固定为唯一条件。

### 导入与备份

选择券商导出文件 → 预览与字段匹配 → 检查重复和异常 → 确认入账 → 对照现金和持仓 → 更新资产快照 → 自动保存及按备份规则备份。

恢复备份时先预览备份时间、内容范围与研究数据引用，原记录的处理方式明确显示；恢复检查失败时保留现有可用数据。具体保留与替换机制仍需细化。

| 进度变化 | 已报告进度间 120ms 过渡，数值不插入虚假进度。 | 直接显示报告进度。 |
| 任务完成与保存反馈 | 勾号、短淡入和可进入结果的提示。 | 显示相同文字与状态。 |
| 多任务状态变化 | 每项状态稳定更新，批量完成合并提示；任务行不因进度变化持续重排。 | 同样保持位置，仅更新数值和文字。 |
| 操作路径播放 | 用户主动启动，按日期推进，可暂停、步进、跳到事件。 | 步进直接切换，不产生额外运动。 |

交互反馈不依赖动画才能识别。降低动态效果遵循系统偏好和软件设置；数值默认不滚动计数，不持续闪烁或自动轮播。

## 真实界面原型与还原验收

生成图片表达风格和构图，不能保证最终界面的每个像素、控件状态和动画。下一步建议制作使用真实前端组件、字体、图表和设计令牌的可运行界面原型，先用明确的演示数据覆盖关键状态。该步骤涉及界面编程，需等待用户明确允许开始。

优先验证账户总览及通行证完整视图、任务中心及多个回测工作区、个股日线。确认后的布局和组件应直接进入后续桌面应用，逐步接入真实数据与任务服务，避免重新从生成图猜测实现。

| 验收对象 | 建议核对方式 |
| --- | --- |
| 布局与令牌 | 在约定窗口尺寸下检查导航、通行证、图表、表格与辅助区；颜色、字号、间距、圆角来自同一套令牌。 |
| 专属图标 | 检查应用标识在桌面及标题栏等位置的小尺寸轮廓、18／20／24px 功能与按钮图标、44／52／72px 徽章；核对按钮各状态、名称、点击区与焦点，同义操作使用同一图形。 |
| 通行证 | 从账户数据配置修改目标，检查主区只呈现轨道；验证滚轮、拖动、键盘、边界滚动、按需详情和达标动画，浏览位置不得改变账户进度。 |
| 多任务 | 用演示任务覆盖运行、排队、暂停、恢复、失败和批量操作，验证操作范围和视图切换；真实计算调度能力在服务接入后另验收。 |
| 股票与图表 | 点击名称代码、返回原位置、选择日期、缩放曲线、定位成交记录；图表标签保持可读。 |
| 尺寸和动画 | 检查 1440×900 等基准窗口、窄窗、Windows 100%／125%／150% 缩放、字体放大及减少动态效果。 |
| 桌面实际显示 | 在 Windows 桌面壳内重新核对字体、边框、滚动、焦点及窗口行为；浏览器预览不代替桌面验收。 |

后续以用户确认的真实原型、设计令牌及逐项验收记录作为还原标准。主要视觉和行为可以按此落实；数据长度、字体渲染和缩放差异需要在实际窗口中处理，不能提前承诺与生成图片逐像素一致。

## 后续评审重点

1. 账户通行证的阶段基准、资金流调整、达标与回撤规则、目标修改生效范围；目标收益率与阶段数可配置已确认。
2. 收益、亏损、回撤等指标定义，以及默认曲线组合。
3. 股票池全选范围、完整上市板块分类及非股票单选的全局规则边界。
4. 单股票多策略的执行模式、策略冲突、退出规则及下一交易日模拟成交口径。
5. 大盘风格、龙头、资金、异动和连板等具体算法与数据覆盖。
6. 情绪估值的系数、行业基准、预设校准与“严重低估”判断标准。
7. 主窗口关闭、托盘继续、退出保存，以及恢复列表的默认操作。
8. 第一版优先实现的页面与流程，图表库、安装更新和导出形式。

这些问题决定最终内容与实现，当前初稿先保证页面、状态和操作关系完整，后续逐页调整。
