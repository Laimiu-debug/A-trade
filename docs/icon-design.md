## 四类图标的分工

| 类别 | 造型与用途 |
| --- | --- |
| 应用标识 | A 字形与波段曲线共用一个轮廓，蓝色圆角方形底；用于识别 A-trade 本身。 |
| 功能与操作 | 统一网格、圆端点和描边，默认清晰的线性图形；用于快速识别入口、动作和状态。 |
| 图表标记 | 买入、减仓、退出、止损及风格变化沿用设计令牌中的三角、菱形、方形等语义，同时显示文字。 |
| 成就徽章 | 银边蓝色晶面和波浪纹样，集中用于通行证；普通操作按钮使用线性图标。 |

专门设计包括轮廓、线宽、留白、尺寸、状态和动效的一致性。返回、播放、暂停、停止及窗口控制保留用户熟悉的含义；相同动作在全软件使用同一个图形。禁止用 emoji 或不同风格的素材临时补位。

## 应用主图标

主标识将大写 A 与一条波段线融合。波段线形成字形的一部分，简化到单色后仍可识别。常规应用图标采用白色符号与蓝底，单色和反白版适用于不同底色。

| 使用场景 | 设计要求 |
| --- | --- |
| 桌面、开始菜单与安装入口 | 同一主标识；应用名称显示在图标外，不塞进图标内部。 |
| 任务栏、窗口标题栏 | 使用小尺寸专用轮廓，波段缺口清楚，避免细节挤在一起。 |
| 首次引导与应用信息 | 标识与 A-trade 字标组合，可放大展示。 |
| 系统托盘如启用 | 优先采用简化单色轮廓，保持对比度；图中示例不代表已决定关闭到托盘或后台常驻行为。 |

应用标识不以旋转或循环闪光表达任务进度。加载及任务状态由对应控件呈现。

后续生产资产计划包括可编辑的矢量母版、单色版、透明背景 PNG 和 Windows 图标包。拟检查 16、20、24、32、40、48、64、128、256px 等使用尺寸；按小尺寸重新校正留白与线条，不能仅缩小同一张大图。当前图片中的圆角与亮面只是视觉方向，未输出独立 SVG 或 ICO 文件。

## 操作图标

按钮图标板按以下六组组织，每组六个图标。

| 分组 | 图标清单 |
| --- | --- |
| 导航与编辑 | 返回、前进、新增、编辑、保存、删除。 |
| 搜索与选择 | 搜索、筛选、全选、清空选择、刷新、更多。 |
| 内容与记录 | 导入、导出、复制、分享、归档、定位。 |
| 任务控制 | 运行、暂停、继续、停止、重试、任务队列。 |
| 图表查看 | 放大、缩小、平移、重置视图、图层、全屏。 |
| 窗口与折叠 | 最小化、最大化、还原窗口、关闭、展开、收起。 |

清空选择使用擦除图形；方框中的短横线留给复选框半选状态。停止使用方形，关闭使用叉号，删除使用垃圾桶，三者不互换。继续保留开始位置提示，重试使用回转箭头，并分别带“继续任务”“重新运行”等准确文案。

图形复用基于同一含义：导出报告、导出流水共用导出符号；移除筛选可使用清空图形；加入跟踪可使用新增符号配合明确文字。备份恢复采用对应业务图标，不能把普通刷新标成数据恢复。下载行情也不能被图标暗示为自动更新本地 TDX 日线文件，仍遵循数据源能力约定。

交易相关按钮以“记录买入”“记录卖出”“保存计划”等实际动作命名，不把记录或计划图标当成已成交反馈。买入、减仓、退出的曲线标记沿用图表令牌，颜色之外有形状和文字。

## 按钮与状态

| 状态 | 图标和交互反馈 |
| --- | --- |
| 普通 | 清晰的单色轮廓或主按钮上的反白图标，与文字基线对齐。 |
| 悬停 | 背景与图标颜色轻变，约 120ms；按钮不移动。 |
| 按下 | 更深的底色及即时反馈，点击区、图标位置和按钮宽度保持稳定。 |
| 键盘聚焦 | 显示独立的 2px 焦点轮廓，不只改变图标色。 |
| 禁用 | 降低强调并提供不可用原因；不响应动作。 |
| 处理中 | 原动作图标位置可替换为小型忙碌指示，文字为“保存中”等；预留宽度，不挤动相邻按钮。 |

功能图标默认 18px，导航 20px，较大入口 24px，24×24 设计网格，描边约 1.75px；小尺寸按实际视觉效果修整。图标与按钮文字间距建议 6–8px，独立按钮点击区至少 32×32px。窗口操作区适配桌面壳的实际可点击范围，不将小图形边界直接当作点击区。

状态符号也纳入专属规范：完成为圆圈勾号、失败为圆圈叉号、警告为三角感叹号、信息为圆圈信息符号、排队为时钟、暂停为双竖线、未连接为断开的连接符号；配文字区分含义。表单勾选、半选、单选、日期、可见性及排序图标遵守同一线条规范和常用含义，后续组件资产逐项制作，不从设计板截取小图。

多任务列表以静态状态符号和真实进度为主，避免每行旋转。仅正在响应用户动作的按钮可显示忙碌动画；减少动态时用静态标记与状态文字。暂停、继续和停止的状态以任务实际响应为准，请求发出时显示“正在暂停”等处理中说明。

纯图标按钮必须有可访问名称、悬停提示和键盘焦点。危险操作、含义不明显的业务动作保留文字；不能只用自创图案要求用户猜测。

## 后续资产制作与验收

当前已绘制应用主标识、36 个操作图标和 36 个功能图标的评审板，沿用已有五个主导航与六种里程碑主题。上述清单覆盖设计范围；全套可用的独立矢量资产、Windows 图标文件和组件状态仍需在造型确认后制作。

后续制作时，每个语义图标使用稳定名称和同一份源资产，同义入口引用同一图标，避免页面各自绘制。基础轮廓、状态角标和徽章光效分别管理。复杂图案的小尺寸版可以简化，但保持识别特征。

实际验收检查：浅色与反白背景、Windows 不同缩放、18／20／24px 功能图标、应用小尺寸轮廓、按钮状态与点击区、纯图标按钮的名称和焦点、暂停与停止的差异，以及减少动态设置。设计稿中的放大预览和尺寸标签不能代替这些检查。
