# 策略研究设计

状态：需求讨论中的设计记录，尚未开始功能开发。

本文件区分用户授权助手决定的策略扩展接口方向，以及仍需讨论的回测、权重与报告方案。已确认功能范围以 [需求讨论记录](requirements.md) 为准。

## 策略扩展接口方向

按用户授权，采用独立策略文件、统一策略接口与注册入口，便于后续增加策略。具体文件名、语言与依赖在技术栈确定后选择。

| 接口组成 | 设计方向 |
| --- | --- |
| 策略描述 | 唯一标识、名称、版本、说明、所需数据与预热长度。 |
| 参数定义 | 策略参数与通用交易管理参数分别描述名称、类型、默认值、取值范围、相互约束与说明，供设置界面和参数扫描使用。 |
| 统一输入 | 截至当前模拟时点可获得的行情、市场风格情绪、参数与持仓状态。 |
| 选股结果 | 输出符合策略筛选条件的股票及理由，用于单策略选股和交集研究。 |
| 交易规则 | 定义买卖、减仓、部分止盈与退出条件，输出交易意图、目标数量或仓位比例、信号强度及理由；支持波段策略所需的剩余持仓及阶段状态。 |
| 交易计划 | 输出信号生成日期、计划执行交易日、买卖或退出条件，以及收益预期的历史依据；支持晚间形成信号、下一交易日操作。 |
| 兼容性声明 | 声明适用环境、关键筛选条件及已知互斥关系，包含冲突的条件、作用范围和理由，供组合检查使用。 |
| 生命周期 | 支持初始化、行情更新、成交反馈及结束处理，避免不同回测任务共享策略状态。 |
| 状态保存与恢复 | 为跨软件退出及电脑重启的任务恢复保存策略运行状态；接口字段、兼容性与保存边界继续细化。 |
| 决策记录 | 输出判断时点、触发条件及对应数值、策略与市场环境依据，将交易计划与实际模拟成交关联，供回测路径查看使用。 |
| 策略注册 | 注册后由策略列表、回测任务及报告统一引用；新增策略通过实现接口并注册完成接入。 |

- 后续提供接口文件、策略模板与注册入口。
- 策略负责筛选与交易判断；统一回测引擎负责模拟成交、账户记账、费用计算与结果统计。
- 通用指标、市场环境与报告组件供策略复用。
- 每次研究保存策略版本、参数及输入数据标识，支持追溯和复现。
- 信号、仓位和成交分开组织的参考：[QuantConnect 框架说明](https://www.quantconnect.com/docs/v2/writing-algorithms/algorithm-framework/overview)。这是接口设计参考，具体回测框架尚未选定。

## 已确认的日线信号与执行时序

- 日线是主要研究基础，用户晚上做研究或回测，次交易日才能操作。
- 在交易日 T 晚间，依据截至 T 已完成的日线与当时可获得的市场信息，研究适用策略或多策略交集并判断买卖条件。
- T 晚间产生的买入与卖出信号，都在下一交易日 T+1 执行。止盈、止损、减仓及部分止盈也按晚间判断、下一交易日执行处理。
- 所有单策略、个股多策略、交集回测及收益平原研究，使用一致的时间顺序。
- 下一交易日的成交时点与模拟价格规则尚未确定。
- 回测应按执行日的可成交价格及费用计算收益；退出条件中的触发阈值与实际执行价格分别记录。
- 时序与模拟成交参考：[日线数据的可用时点](https://www.quantconnect.com/docs/v2/writing-algorithms/key-concepts/time-modeling/periods)、[成交模型中的未来信息与开盘成交处理](https://www.quantconnect.com/docs/v2/writing-algorithms/reality-modeling/trade-fills/supported-models/equity-model)。具体 A 股规则仍按股票市场和历史日期处理。

## 交易指导的输出

已确认需求：研究支持策略或交集适用于当前环境时形成交易信号，包含预期收益、退出条件及市场风格转变风险，为后续操作提供指导。

### 建议的输出内容与估计方式，尚未确认

| 输出内容 | 建议记录的信息 |
| --- | --- |
| 股票与信号 | 股票名称、六位代码、买入或卖出信号、生成时间与计划执行交易日。 |
| 研究依据 | 参与策略及版本、参数、交集条件、当前市场环境与匹配理由、所依据的历史验证区间。 |
| 收益预期 | 可比历史样本的收益分布、典型收益区间、持有周期、亏损比例及样本数量，明确是否扣除费用。 |
| 持仓与退出计划 | 持仓数量与比例、止盈、止损、减仓或部分止盈数量、剩余仓位的后续条件，标明晚间判断后次交易日执行。 |
| 风格转变风险 | 环境变化信号、对原策略的影响、建议动作及其研究依据。 |

- 基于信号生成时点之前可获得的历史样本估计预期收益，保留估计版本和样本区间，便于事后复盘。
- 分开展示统计收益预期与策略止盈目标；止盈阈值用于判断退出，收益预期反映历史条件下的统计表现。
- 样本不足或环境无法匹配时，说明估计依据不足，避免输出没有数据支撑的确定收益数字。
- 策略、交集组合或退出规则的历史表现，需在后续独立区间验证；“当前环境下有效”的判定标准仍待讨论。

## 市场风格转变研究

已确认需求：关注风格转变后的收益下降，给出转变风险提示及交易建议，回测需要研究这种变化。

### 建议的验证方法，尚未确认

- 逐个历史时点根据当时已知信息识别风格与情绪，记录识别结果及变化原因；用于交易判断的环境状态保持当时版本。
- 分别呈现不同环境，以及转变前、转变中、转变后各阶段的收益、回撤、交易次数和持仓表现。
- 保留不调整的对照组，研究暂停新买入、调整仓位、退出持仓或切换兼容策略等候选动作；具体动作需由对比结果支持。
- 转变在 T 晚间被识别后，对应操作仍在 T+1 执行；评估识别延迟、次日跳空及交易成本对结果的影响。
- 将持仓的原始收益预期与环境变化后的重新评估分别记录；建议应说明触发原因。
- 用滚动训练和后续区间验证检查环境规则及退出条件；参数平原同时研究参数稳定性和跨环境表现。
- 方法参考：[QuantConnect 滚动优化说明](https://www.quantconnect.com/docs/v2/writing-algorithms/optimization/walk-forward-optimization)。

## 已明确的多策略交集含义

用户所说的多策略交叉是选股结果交集，支持多个策略共同筛选，不限于两个。

两个策略的解释示例：A 选中 10 只、B 选中 9 只，两者共同选中 3 只，再研究这 3 只的历史表现。多个策略时，在同一选股时点计算所选策略结果的共同交集。

### 建议的研究方法，尚未确认

- 在每个历史选股时点，使用当时已知数据计算各策略选股结果，再取交集。用同一时点的结果筛选后续交易机会。
- 比较参与组合的各策略单独选股结果与完整交集结果；可按研究需要比较选定的子组合。各组使用相同数据区间、资金、买卖规则、仓位、费用和基准，评估交集筛选本身的作用。
- 比较收益、最大回撤、交易次数、持仓时间、资金利用率及样本外表现，检查改善是否依赖少量交易。
- 交集有机会筛选出更符合共同条件的股票，也会减少样本和交易机会。是否改善结果需要通过对比得出，不能仅凭符合策略数量下结论。
- 检查策略筛选依据是否高度相似；保留各策略筛选数量、交集数量及条件解释，帮助理解筛选变化。
- 记录逐步加入策略后候选股票数量的变化，区分规则冲突、正常无匹配与所需数据缺失。
- 后续讨论交集更新频率，以及股票离开交集后是否退出持仓，或者仍按既定退出规则管理。
- 个股多策略回测与选股交集研究分别保留：前者的独立对比或组合方式尚未确定，后者按用户已明确的交集定义设计。

## 策略冲突

已确认需求：多个策略参与时，需考虑部分策略本质上互相冲突。具体冲突处理规则尚未确认。

### 建议的分类与处理方式，尚未确认

| 情况 | 建议的处理方向 |
| --- | --- |
| 筛选条件逻辑互斥 | 针对同一对象、同一时点且可确定互相矛盾的条件，指出冲突条件和策略；全交集组合提示无法同时满足。冲突策略仍可各自独立回测和比较。 |
| 适用市场环境不同 | 根据当时的风格情绪判断哪些策略可启用；研究是否使用分组及环境切换，具体方式待讨论。 |
| 同一股票交易意图相反 | 在运行时记录买卖冲突，按照预先明确的优先级、否决或跳过规则处理，规则与结果写入报告。 |
| 筛选依据高度相似 | 记录信号重叠与相关性，评估新增策略是否提供额外信息。 |

- 配置组合时检查已声明、可判定的冲突；运行时继续检查当前条件及交易意图。
- 任意策略代码的全部冲突无法仅靠静态声明保证识别。对无法判断的关系显示尚未验证，并保留运行记录和解释。
- 根据具体条件判断兼容性，避免仅凭策略名称或类别断定冲突。
- 筛选全交集时保留所选策略的全部条件；冲突或空交集应明确展示原因，不自动删除条件或切换组合方式。
- 相互矛盾的必要条件需先解决组合逻辑，再考虑权重；权重主要用于兼容策略的参与程度或交易意图汇总。
- 报告记录参与策略、组合规则、冲突或未知关系、处理规则，以及处理造成的筛选和交易变化。

## 收益平原

已确认含义：在单策略或多策略条件下扫描参数，寻找参数变化下的收益稳定区间和合适参数。研究范围包括策略参数，以及持仓管理、止盈止损、持仓数量和仓位比例等数值变化。

### 参数范围的整理建议，具体口径待讨论

| 参数类别 | 可纳入研究的内容 |
| --- | --- |
| 策略与组合 | 单策略或所选多策略组合的筛选与交易参数。 |
| 持仓管理 | 同时持有的股票数量、单股数量或资金比例、总仓位比例；持仓数量的具体口径待明确。 |
| 止盈止损 | 盈利或亏损触发阈值，以及策略支持的其他退出参数。 |
| 部分止盈 | 减仓触发条件、减仓比例、剩余仓位退出条件；是否支持多个阶段待讨论。 |

- 单股层可研究该股的仓位比例与退出规则；涉及同时持有几只股票时，建议使用组合层回测，在同一资金账户下模拟候选股票之间的分配。
- 研究持仓周期、移动退出等其他参数是否纳入扫描，后续按策略需求确定。

### 建议的评估方式，尚未确认

已确认参数寻找区间与后续验证区间分开，并展示样本量、环境表现和验证状态；以下补充评估细节仍待讨论。

- 展示参数网格或热力图，观察邻近参数变化时收益与回撤的稳定程度。
- 同时查看交易次数、风险、费用与不同历史区间表现，研究一片参数区域的稳定性。
- “合适”的评价标准需明确收益、回撤、资金利用率及稳定性等目标和约束；展示符合条件的稳定区域及候选参数，并记录选择依据。
- 在已确认的独立验证基础上，讨论增加滚动验证；扫描结果与验证结果分别呈现。
- 参数扫描沿用已确认的 T 晚间信号、T+1 买卖时序；止盈止损及风格转变处理规则也要在该时序下验证。
- 分析稳定参数区域在不同市场风格及转变阶段的表现。
- 报告保存搜索范围及尝试次数，并说明候选参数的选择依据。
- 方法参考：[QuantConnect 参数优化文档中的过拟合与未来信息问题](https://www.quantconnect.com/docs/v2/writing-algorithms/optimization/parameters)。

## 减仓与部分止盈

已确认需求：回测应支持减仓止盈和部分卖出，并继续管理剩余持仓。

### 建议的模拟与统计方式，尚未确认

- 交易事件记录部分卖出的计划数量或比例、实际成交数量、日期、价格、费用、触发原因，以及成交后的剩余持仓。
- 减仓条件在 T 晚间判断，在 T+1 模拟执行；实际成交后更新仓位、现金、已实现收益和剩余持仓状态。
- 部分卖出后继续跟踪剩余持仓，按后续止盈、止损、策略失效或市场环境变化等规则处理。
- 如果采用多个止盈阶段，分别定义阈值、比例与执行状态，避免同一阶段重复触发；具体阶段数后续讨论。
- 明确减仓比例相对于初始仓位还是当前剩余仓位，以及条件同时触发时的优先级。
- 可卖数量、交易单位、费用及无法成交的情况由统一引擎处理；未成交的计划与实际成交分别记录。
- 一次持仓波段可以包含多笔部分退出。报告分别展示成交笔数与完整持仓波段统计，汇总已实现收益、剩余持仓盈亏及资金曲线。
- 用相同资金和交易约束比较全部退出与部分退出的不同规则，研究收益、回撤和资金利用率的变化。

## 回测操作路径查看

已确认需求：获得优质回测结果后，能够查看该次回测整条路径上的操作记录，理解交易过程并指导后续操作。

### 建议的查看入口与呈现方式，尚未确认

- 在回测详情提供“操作路径”入口；从报告库或收益平原的候选结果进入相应运行的操作记录。
- 将日线图上的操作标记、按日期排列的操作记录、持仓与资金变化联动呈现。
- 支持查看整个回测区间，也可以聚焦某只股票或某个完整持仓波段。
- 按步骤查看每个晚间判断及次交易日执行，解释买入、继续持有、部分退出及最终退出的过程。
- 选择某条记录时定位到对应历史日期和行情；查看个股页面后返回，保留原回测记录位置。

### 建议的记录内容，尚未确认

| 内容 | 建议记录的信息 |
| --- | --- |
| 回测身份 | 对应运行、策略与参数版本、组合规则、数据版本及回测区间。 |
| 操作对象 | 股票名称与六位代码，所属持仓波段。 |
| 决策与计划 | 晚间判断日期、计划执行交易日、买入、持有、减仓或退出意图，以及目标数量或比例。 |
| 判断依据 | 当时的筛选条件及数值、交集命中情况、止盈止损触发条件、市场风格情绪及其变化。 |
| 执行结果 | 模拟成交日期、数量、价格、费用；未成交或部分成交时的原因和剩余计划。 |
| 持仓与资金 | 操作前后持仓数量与比例、现金、已实现收益、剩余持仓盈亏及总资产。 |
| 后续过程 | 剩余持仓如何继续管理、下一次触发条件，以及完整波段最终结果。 |

- 将当时形成的判断和之后发生的结果分别保存，查看时使用该次运行的历史记录。
- 建议所有保存的回测结果均能查看路径，便于比较不同候选参数、成功与失败的研究结果；优质结果的评价标准仍需讨论。
- 操作路径中的股票展示、点击跳转、返回及选择遵循全局规则。

## 曲线与结果查看

已确认需求：曲线作为重要展示方式，支持收益曲线、亏损曲线以及其他相关曲线，便于理解完整研究和回测过程。下列清单及交互方案为待讨论建议。

### 建议的曲线清单，尚未确认

| 曲线方向 | 希望帮助观察的内容 |
| --- | --- |
| 收益金额与收益率 | 累计收益及各阶段收益变化，区分金额与百分比。 |
| 盈亏与亏损 | 已实现盈亏、剩余持仓浮盈浮亏，以及亏损变化；是否单独累计亏损交易金额等口径待讨论。 |
| 资产与净值 | 持仓和现金合计的资产变化，以及便于比较的净值变化。 |
| 回撤 | 从此前峰值下降的幅度及持续过程；与实际亏损、持仓浮亏分别标注。 |
| 仓位与现金 | 投入比例、持仓数量及可用资金随时间的变化。 |
| 策略与基准对比 | 单策略、多策略交集、不同参数及基准在同一区间的表现。 |
| 行情与市场环境 | 对应行情、市场风格或情绪指标的变化，与收益及回撤关联查看；指标定义和历史数据另行确定。 |

### 建议的口径与交互方式，尚未确认

- 账户曲线明确处理入金、出金、分红及费用，区分资产变动与投资收益；统一记录指标、单位、时间范围及计算口径。
- 对比曲线采用一致的时间范围与收益口径；金额、收益率和仓位等不同单位分图展示或明确标注，避免混淆。
- 支持日期筛选、缩放、悬停查看和曲线显示选择；涉及股票及批量选择时遵循全局交互规则。
- 将买入、减仓、退出和风格变化标记与曲线及操作记录联动，选中日期后查看当时的判断、成交和持仓情况。
- 收益平原中选择参数组合后查看该组合对应的完整收益、盈亏和回撤曲线；研究报告关联保存的曲线数据及配置。
- 如运行过程中展示阶段曲线，明确数据截至日期与任务未完成状态；不将尚未完成的区间作为最终研究结果。

## 市场风格情绪匹配与权重建议

已确认目标：策略应与大盘风格和情绪相匹配。权重是用户提出的可能实现方式，以下机制尚未确认。

- 市场环境模块输出当时的风格、情绪、判断依据与数据可用状态，供各策略使用。
- 策略声明适用条件和不适用条件，先决定当前环境是否允许启用，再决定参与程度。
- 信号组合权重决定不同策略对买卖判断的影响；资金分配权重决定各策略的资金或仓位预算，两者分别设置和记录。
- 第一阶段建议支持用户可配置的基础权重与环境匹配规则，研究报告展示固定权重与环境匹配后的差异。
- 后续如引入从历史表现学习的动态权重，应只使用当前模拟时点之前的训练数据，并在后续时间验证；允许保留现金，避免为了归一化权重而强制满仓。
- 保留各时点权重及其调整原因，支持解释回测结果。
- 历史市场环境必须来自当时可获得的数据；当前 MCP 返回的风格情绪不能直接充当过去的状态。历史覆盖范围和重建方式需在数据接入时确认。
- 时间处理参考：[QuantConnect 参数优化文档](https://www.quantconnect.com/docs/v2/writing-algorithms/optimization/parameters)。

## 回测验证与研究可重现

用户已确认采纳回测验证及研究版本保存功能：

- 参数寻找区间与后续验证区间分开，展示样本量、不同环境表现及验证状态。
- 明确下一交易日的模拟成交价、费用、滑点和无法成交的处理；具体口径仍需讨论。
- 每次研究保留数据、策略、参数及规则版本，便于比较、重跑和复核结论。
- 支持单股、行业集中度、可用资金与总仓位等组合层面的约束；多信号同时出现时的排序和资金分配规则继续细化。
- 研究信号可保存为次日交易计划，关联实际操作、未执行或调整原因，供后续复盘对照。

### 补充建模建议，尚未确认

- 固定并记录 T 晚间的信号生成时点与 T+1 的执行时点，按执行价格、费用及可成交约束计算结果。
- 统一处理原始价格、复权、分红及持仓价值，确认本地数据与 MCP 的历史字段是否足够。
- 按股票所属市场和回测日期处理可卖数量、涨跌停、停牌、交易单位及费用等交易约束。历史回测需要对应当时生效的规则。
- 对日线无法确定的盘中成交顺序明确约定；数据不足时在报告中说明采用的假设。
- 记录股票池与历史状态；批量研究需考虑退市、上市时间及样本筛选对结果的影响。
- A 股交易规则参考入口：[上海证券交易所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)。开发时仍需核对其他市场及历史时期规则。

## 研究任务进度与运行控制

已确认需求：所有研究与回测任务提供进度条及暂停、恢复／继续运行、停止功能，并支持退出软件或电脑重启后从保存进度继续；用户可以同时开启和管理多个回测任务，资源允许时并行计算，遵循全局交互规则。

### 建议的实现方向，尚未确认

- 由统一任务管理机制承载回测、策略交集研究、收益平原等任务，记录运行状态、阶段与进度；策略通过统一接口上报必要进展并响应控制请求。
- 按任务类型选择进度单位，例如历史交易日、股票数量或参数组合；多阶段任务分别展示当前阶段和整体进展。
- 任务状态区分运行中、正在暂停、已暂停、正在停止、已停止、已完成及失败，避免用户无法判断控制请求是否生效。
- 在可保持一致状态的计算边界响应暂停和停止；暂停保存模拟时点、持仓资金、策略状态、已完成参数组合及必要随机状态，恢复时继续剩余工作。
- 使用该次任务确定的数据、策略和参数版本继续运行，避免暂停期间数据刷新改变同一次研究的口径。
- 停止后的记录与部分结果明确标注未完成；完整报告与结论需区分任务完成状态。
- 后台执行与界面交互分离，任务运行时仍能浏览和使用其他页面；持久保存可恢复状态，启动时核验原数据与策略版本，多个任务的调度与资源预算按下述方向细化。

### 多任务调度设计建议

- 统一调度器管理 CPU 工作额度、内存预算和读写并发。任务提交数、打开的结果页数和正在计算的任务数分别记录；可提交很多任务，当前资源不足的任务排队并显示原因。
- 收益平原是包含多个参数组合的父任务。参数组合子任务同样占用全局资源额度，不能由每个父任务各自无限创建进程；父任务进度按真实已完成组合汇总。
- 界面保留交互所需资源。初稿采用“自动分配”模式，并提供高级并发上限和内存预算；默认数值根据机器与实测确定，不承诺任意任务数量下仍然流畅。
- 排队任务可调整优先级，同优先级按提交顺序并考虑资源是否满足；长时间等待任务需要公平调度。优先级影响后续计算片段的调度，不能无提示强杀正在写结果的任务。
- 暂停在一致保存点生效，保存后释放计算额度及可释放内存；继续请求先回到队列，资源就绪后显示运行。任务没有获取额度时不能假装已经继续计算。
- 每个任务独立保存策略实例、模拟账户、输入版本、输出位置和保存点。可共享只读数据缓存，不共享可变持仓或策略状态；一个任务失败不应终止其他独立任务。
- 批量暂停、继续和停止逐项回报实际状态；只对支持动作的选中任务执行，列出不适用项。暂停全部当前任务与暂停队列调度分别提供，后者只阻止启动后续任务。
- 大量任务完成时合并通知，保留可查看的完成列表；更新进度和图表时合并高频事件，避免结果页刷新挤占界面交互。
- 应用重启后展示可恢复任务，再按同一预算调度；部分任务恢复不兼容时单独处理。队列顺序、优先级、父子关系、暂停意图和任务配置均持久保存。
- 资源压力上升时先停止派发新计算片段，并显示等待资源；运行任务如需回收资源，应在可恢复边界保存并显示相应原因。调度重试不能重复登记同一片段结果。

界面上每项任务展示自己的阶段和进度。不同研究类型不直接平均百分比；批次概览可显示已完成任务数／总数，并清楚标注为数量统计。预计完成时间仅在有估算依据时展示。

## 报告库

已确认需求：保存研究成果、得出结论并输出策略研究报告。

### 建议的报告内容，尚未确认

| 内容 | 建议记录的信息 |
| --- | --- |
| 研究问题 | 本次想验证的假设，例如多个策略的选股交集是否改善回撤。 |
| 研究配置 | 股票代码与名称、参与策略及版本、参数、组合规则、区间、数据来源、T 晚间信号与 T+1 执行规则、费用和交易假设。 |
| 回测结果 | 资金曲线、统计指标、含减仓与部分止盈的交易明细、剩余持仓表现及基准对比。 |
| 操作路径 | 关联本次运行的完整操作记录、当时判断依据与持仓资金变化，支持从报告进入查看。 |
| 多策略对比 | 各策略与交集的筛选数量、交易次数及表现差异。 |
| 冲突处理 | 检出的冲突、兼容性未验证的关系、采用的处理规则及其影响。 |
| 参数稳定性 | 单策略或多策略下的策略、持仓及退出参数平原，与后续验证区间结果。 |
| 环境适配 | 不同风格情绪及转变阶段的表现、建议动作对照结果，以及权重调整记录。 |
| 交易指导 | 当时给出的信号、收益预期及其依据、退出条件，与后续实际或模拟结果的对照。 |
| 研究结论 | 本次数据支持的结论、适用范围、样本不足或假设限制，以及后续验证方向。 |

- 按已确认的研究版本保存需求，保留每次运行的配置及结果，支持查看、对比和重跑；具体归档结构继续讨论。
- 结论应有对应结果支撑；未验证、数据不足或效果不明确时如实记录。
- 结论生成方式、报告模板、导出格式及页面交互后续讨论。
- 报告库继续遵循股票名称、六位代码、股票跳转、返回和选择等全局交互规则。
