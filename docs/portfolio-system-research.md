# 多策略轮动、滚动验证与系统收益平原

本页描述第六阶段的高级组合与轮动研究。首次研究请从 [单策略优先六阶段流程](single-strategy-workflow.md) 开始，完成固定参数回测、少量参数平原与冻结后新时段验证。

目标是让软件执行完整的股票池研究流程。设置、运行、暂停、恢复、查看每日账本与验证结论都在回测工作区完成；不需要用户每天让开发者手动回测。回测使用模拟资金，不写入真实账户。

## 运行入口

高级研究任务有四种：`portfolio`（股票池组合）、`comparison`（训练与样本外对照）、`walkForward`（滚动样本外）、`systemPlateau`（四层参数平原）。旧版 `backtest` / `plateau` 报告仍能查看，不能用旧版单策略平原冒充全系统平原。

普通组合可使用最近交易日设置。比较、滚动和平原研究需要在软件里设置明确日期。默认 39 日只是功能预设，不自动降低持续性检验所需样本量。

## 轮动执行

`allocation.mode` 支持 `single`、`equal`、`soft_rotation`、`hard_rotation`。后两种复用原有共享资金账本、成交约束和交易费用。单策略影子账户分别持有自己的 Top N，独立承担同样的手续费、滑点、风险退出与无法成交约束；轮动依据是这些完整账户的历史净收益。

`rotation` 参数：

| 字段 | 默认 | 含义 |
| --- | ---: | --- |
| `lookbackDays` | 20 | 近期净收益窗口 K |
| `cooldownDays` | 5 | 两次权重调整间隔的交易日数 |
| `minWeightChange` | 0.1 | 新旧权重半 L1 距离的最低门槛 |
| `temperature` | 0.05 | 软配权的分散程度 |
| `regimeBlend` | 0.25 | 已知同环境历史表现的混合比例 |
| `regimeMinObservations` | 5 | 同环境表现最少观测数 |
| `warmupDays` | 120 | 实际账户开始前的影子账户预热请求 |

影子账户可以读取回测开始以前的历史；真实账户仍从指定日期的初始现金开始。信息最多截至信号日收盘，成交最早为下一交易日开盘。环境归因使用前一收盘已知的指数状态；缺少指数或足够历史时，该项明确未知，不编造市场状态。同环境数据不足时仅用近期净收益。

软配权使用各策略净收益评分的 softmax；硬切换选择最高评分策略。阈值与冷却期会阻止不必要的调整。轮动触发的卖买实际进入资金账本，即使持仓方式设置为风险退出也一样；停牌、涨跌停和其他拒单仍可能使实际持仓偏离目标。每日记录分别展示策略预算、股票目标和实际股票权重。

单独运行软配权或硬切换是执行诊断，不代表已通过训练持续性检验。`comparison` 才会先在训练段检验持续性，通过后运行冻结样本外的软配权、硬切换、等权和训练选定固定策略。检验失败时保留基线结果并明确跳过轮动，不自动放宽门槛。

## 滚动验证

`experiment` 与 `config` 并列保存。其 `kind` 必须和任务类型一致。可配置训练长度 `trainDays`、测试长度 `testDays`、推进长度 `stepDays`、扩展训练 `expanding` 和折数上限 `maxFolds`。测试窗口不能重叠，最多 8 折。

每折先完成训练，冻结候选参数和固定策略选择，再接触该折测试数据。下一折可以按既定时间表使用那时已知的数据重新训练。`capitalMode=independent` 保留各折从相同初始资金、空仓开始的诊断。`capitalMode=continuous` 在诊断之外运行四个连续资金账户，不将重置账户的结果拼接。

连续账户从第一折样本外初始现金开始，首个信号在该折首日收盘生成。以后跨折保留现金、持仓、成本、交易波段、待到账现金、认购权益、T+1 锁定与风险状态。软配权和硬切换按每折训练选择交接；等权和固定策略冻结首折训练参数，固定策略 ID 也只在首折选择。窗口间有空档时继续按旧方案交易。交接在下一折之前的收盘形成新计划，旧未成交目标明确标为替代，新的换仓实际承担费用和无法成交约束。持续性不足的折使用等权预算，并明确不能证明轮动价值。

## 四层扫描与邻域

`systemPlateau` 必须同时包含以下四层轴，且扫描参数必须影响实际参与分配的策略：

| 层 | 示例路径 |
| --- | --- |
| 策略公式 | `strategies.momentum.params.lookback` |
| 子策略组合 | `combinations.combo_weighted.method`、`combinations.combo_weighted.children.momentum.weight` |
| 轮动 | `rotation.lookbackDays`、`rotation.minWeightChange`、`rotation.cooldownDays` |
| 持仓与换仓 | `topN`、`maxPositions`、`maxStockWeight`、`switchThreshold` |

每轴包含 2 至 5 个事先声明的值，最多 8 轴、81 组参数，并限制总引擎运行数。报告分别记录唯一参数组合数、各折候选评价次数和实际引擎运行次数。参数交互导致非法配置时，在读取股票池以前拒绝任务。

邻域由本点与单轴相邻一步的数值点组成；组合方法属于类别，其他方法都是类别邻居。没有跨空洞的距离拼接。稳健性评价使用邻域平均净收益、收益标准差、正收益占比和有效点数量；交易成本已包含在净收益中。

先找出训练邻域达标点，再按网格相邻关系形成连通区域；报告每个区域的均值、标准差、正收益比例、包围盒空洞和各轴宽度。训练段冻结整个区域和其中的代表点，样本外只验收或否决这个区域，不根据测试成绩缩小网格、换代表点或追加调参。热图使用实际计算值；没有执行轮动的点标出等权诊断口径。

推荐区间必须覆盖已通过证据的完整离散笛卡尔积，并且各轴都有经过验证的宽度。L 形、孤点、网格缺口等不能投影为矩形区间；即使所有点收益为正也不例外。推荐的离散取值不意味着它们之间未扫描的连续插值已验证。

验收的质量与持续性门槛针对训练预先冻结的区域、区域内完整证据以及实际对照账户。区域外失败参数保留在热图，不能反过来否决一个已在训练期选定且证据完整的区域，也不能根据样本外结果把失败点从冻结区域内剔掉。

验证要求覆盖至少两个样本外年份、至少两个实际观测到的市场环境；每个冻结区域成员都需要相应证据。证据不足、邻域不稳定、持续性失败或轮动没有超过对照时，报告失败原因并保留真实结果，不兜底推荐最高收益单点。

## 审计、恢复与数据边界

服务先创建任务，后台分批读取完整股票池并冻结快照；读取批次不截断投资范围。四种新任务共享一个重型执行名额。快照、参数、版本、训练选择、当前引擎和逐折结果持久化到研究数据库；恢复继续使用原快照。引擎版本变化时，旧报告可读，旧的未完成任务不能当成同一版本直接续跑。

`research.get` 支持 `resultPath` 选择一个嵌套账户，例如 `folds.0.testing.softRotation`、`continuous.runs.equalWeight`，并独立分页每日记录与轮动日志。每个账户的 `pagination.path` 是可用于下一次请求的实际路径。“保存完整报告 JSON”通过原生保存窗口导出所有账户、每日、成交、公司行动和轮动记录，无分页截断；另一个按钮明确导出当前报告页。未完成任务的完整文件仍标记为阶段结果。

本地现存股票文件并非完整历史成分，缺少分红、送转、配股等权益记账时，也不能把原始价格模拟认证成真实总回报。统计诊断与数据认证分别记录。缺少数据不会被收益为正抵消；框架测试证明执行逻辑、时序和恢复一致性，不证明策略有投资价值。

可以在回测工作区导入历史 JSON / JSONL 数据包。服务验证原始价格、独立日历、逐日成分、退市记录、历史 ST 和交易状态、参考昨收与完整权益事件；通过后保存不可变分块 SQLite 记录及内容校验。研究按证券分块读取对应范围，保留最多 500 根指标预热和主散量能的精确前缀状态，不按证券数量裁掉股票池。信号价格按当时参考昨收因果调整，执行仍使用原始价格。协议和格式示例见 [历史包与权益模型](portfolio-history-format.md)。

权益账本分开记录登记、除权、现金实际到账、股份上市、配股认购付款与失败退款；待到账现金计入净值但不能提前买股。现金模型为外部声明的每股税后净额，不自动计算个人持股期限相关的递延股息税。非整数股份、缺少结算证据等不支持事项阻止认证。`certified` 指包内完整性和本模型下的可核算性，范围为 `internallyValidatedDeclaredUniverseAndNetCashModel`；不代表软件独立验证了数据商全部历史事实。

服务登记同一声明来源/股票池的样本外使用区间。完全相同数据与设置的运行标为复现，不增加独立证据；改变设置或数据后与以前区间重叠，标为开发样本，取消轮动验收与平原推荐。预先声明的单次网格内候选不互相污染。登记限于此工作区，不能识别用户在其他软件中已经看过的样本。

关键结论始终针对样本外净收益：软配权未超过等权组合就报告“轮动没有创造价值”；超过等权但未超过训练选定的固定策略，关键检验仍未通过。不会为了改善这个结论继续使用同一测试段调参。

## 页面设置、股票池浏览与任务管理（2026-10-12）

“按当前设置筛选股票池”创建后台 `poolPreview` 任务，使用研究结束日收盘；最近 N 日模式使用来源最新交易日。筛选遍历完整股票池，采用同一 `DailyScorer` 的基础资格、分层池和策略信号，完成后才分页。页面可切换四种池与基础排除名单，查看名称、代码、价格、成交额、趋势涨幅、结构回撤、量能倍数、触发策略和排除原因。搜索在完整匹配池内执行，不局限于当前页。修改设置后旧结果标出需要重新筛选。筛选不产生交易、净值或收益结论。

任务中心支持按名称、类型、日期和状态查询，新建、重命名、编辑未冻结任务、复用/复制设置、删除记录，以及原有暂停/继续/停止。已有输入快照或结果的任务不会原地改参；复用设置会创建新任务。运行或保存中的任务先停止并等待保存，再删除。删除任务会清理不再被引用的输入快照，保留样本外使用记录；用户另存的报告文件不因软件记录删除而消失。旧版任务保留查看、重命名、删除，新表单不无损支持的自定义策略实例不会被静默改写。

## 按 final trade 前端流程整理（2026-10-12）

回测工作区采用五步导航：股票池、策略与组合、交易规则、创建任务、查看结果。可随时返回任意步骤，编辑设置自动保存在本机；新任务创建后在第五步展示实际进度和结果。第五步不重复挂载配置表单，避免进度刷新时重建隐藏编辑控件。现有任务中心与报告库仍可进入任务详情。

第一步直接展示基础资格与四种股票池卡片；趋势、结构、量能池分别从基础池产生，明确可以重叠。每张卡片显示筛选数量并可查看对应股票。筛选仍遍历完整范围后分页，不增加证券数量截断。筛选预览不依赖尚未填写的资金、策略配权和组合设置，不模拟账户或产生订单。

第二步选择基础策略、入口池与组合方式，具体策略参数默认折叠。支持按策略保存、套用、删除命名参数预设，恢复策略默认参数；预设同时保存入口池，在本机持久化。组合子策略权重独立展开。

第三步区分每日重算股票池/评分与实际持仓调整，保留风险退出、排名换仓及混合模式。仓位数量、单股新买目标上限和止损/止盈/回撤直接设置；交易成本、权益处理和轮动细节按需展开。T 日收盘出信号、下一交易日开盘尝试成交及 T+1 约束继续由原账户引擎执行。
