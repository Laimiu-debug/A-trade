# 账户与复盘（2026-10-11）

桌面版的账户页面读取独立的真实 SQLite 账本。首次进入没有账户、成交或收益；旧版显示偏好和笔记保留在工作区状态文件。资产快照可以读取已配置的[本地个股日线](market-data.md)填充价格，保留价格日期、来源和缺失状态。浏览器独立预览继续使用演示账户数据。

## 开始记账

1. 创建实盘记账或模拟账户，填写起算日期和期初现金。
2. 若起算时已有持仓，添加“期初持仓”及当时的总成本；不要重复录入起算之前的买入。
3. 在交易管理中录入成交、导入截图，或补充入出金、分红和费用。现金不足或卖出超过持仓会拒绝保存。
4. 在资产快照中选择日期，按该日真实持仓填写价格，或从已配置行情读取截至该日的收盘价。检查来源与日期后保存；缺价不会由演示行情补齐，也不会读取未来日线。

账本用十进制计算金额，买入费用计入成本，部分卖出按移动平均成本分摊。修改、作废或导入历史记录会重放后续账本；发现任何一笔无效时整次操作回滚。资金流、已实现损益与未实现损益分开显示。当前不支持融资融券、多币种和衍生品核算。

## 同花顺成交截图

在“导入与对账”选择截图或粘贴截图。配置支持图像输入的 AI 模型后，点击识别，将本次选中的图像发送到配置的 API 服务。原图不会写入账户数据库。每批最多 4 张，单张最大 5 MiB，合计最大 12 MiB，支持 PNG/JPEG/WebP。

识别结果只进入待核对表：买卖方向、完整成交日期、代码、数量、价格、费用和成交编号都可以更正。没有年份的日期、截图未提供的费用等不会被猜测；人工补充并确认每一行后才能入账。只接受已成交买卖，持仓截图、委托和撤单不能直接当成交导入。识别结果不能保证正确，最终以券商成交与交割明细核对。

同时支持 CSV/TSV、XLSX 和 JSON。CSV 支持常见中文编码，可处理表头映射；旧版二进制 XLS 请先另存 XLSX/CSV。使用成交编号及文件行标识识别重复，合法的同价同量分笔成交仍保留。整批交易需要通过余额与持仓校验才会提交。

成交金额与数量乘价格、费用合计与分项不一致时，会保留原文件数字并列出差异。需要明确选择采用来源值、计算值或已手工修正的值，再次校验后才可导入；重复校验不会抹掉未处理的冲突。采用来源费用合计时统一计入其他费用，避免与原分项重复相加。

交易流水、逐笔复盘入口和关联成交选择支持搜索、日期范围及分页。关联勾选跨页保留，不再限制只能选择最近 100 笔。股份调整使用有符号股数：正数增加股份，负数减少股份；调整后持仓仍须通过账本校验。

## 复盘和计划

每日、周度、月度、逐笔/回合、盘前想法使用不同模板，细分市场环境、持仓逻辑、逐笔证据、风险预算、情绪纪律、归因、改进动作与下一周期情景。可关联原始成交；交易计划记录触发条件、止损止盈、计划数量、执行状态、实际成交和偏差。

评分使用版本化的六个维度、24 个子项，每项 0–4 分，并填写依据。未填写、缺少依据和不适用分别处理，界面同时展示覆盖率；本版规则为暂定过程评价，不把盈利直接判为好交易。完整口径见 [参考实现笔记](account-reference-notes.md)。复盘可通过 JSON 或 Markdown 导入，旧项目评分保留原义，不强行映射成新量表。

AI 复盘仅在主动点击时生成独立草稿；它获得选定账户、所选期间及显式关联成交的必要片段，不获得其他账户、API Key 或全库备份。人工采纳后才进入编辑内容，最后保存才写入账本。当前没有连接策略、回测和市场研究，提示词 `account-assistant-v1` 与量表 `account-review-v1` 后续会迭代。

逐笔未提交草稿按账户与成交分别保存，返回同一笔成交时恢复相应草稿。快速复盘与详细模板可以切换，已有正文和评分继续保留；事实材料可按所选日期带入，人工判断与评分不会自动生成。评分汇总使用与正式保存相同的后端规则，随当前输入更新。

交易计划展示关联成交的实际数量、均价、费用及执行比例，并提示不匹配或已作废的关联；自动计算结果与人工执行状态分开显示。AI 复盘也会包含与本次成交相连的周期外计划，便于对照较早制订的计划；执行汇总涉及本次未提供的成交时不发送该汇总，避免后续成交混入历史复盘。

波段统计以单证券建仓到清仓为一回合。明确证券且发生在持有期间的分红与独立费用纳入回合总损益，价差损益单列；无法确定归属的款项保留在账户层并提示，不任意分摊到历史回合。胜率、盈亏比、平均持有天数等均标明样本，未结束回合不混入已结束统计。

曲线可以切换资产、净投入收益率与可比快照回撤，并按日期追溯成交、资金、复盘和计划。净投入收益率仍为简单口径，不能当作时间加权收益；入出金、期初持仓、净投入变化或缺价都会中断回撤可比区间，每段至少两份完整快照才参与计算，等额入出金也会断段。日线日期早于所选日期时显示旧价提示，读取行情不会自动写入快照。

删除已导入复盘时同步处理其导入标记，允许用原文件重新导入恢复；仍然存在的档案继续按来源标记去重。

## AI 配置

在「设置 → AI 模型」统一管理全局配置，所有账户和模块共用。文本处理与图片识别分别填写兼容 Chat Completions 的 API 根地址（例如 `https://服务域名/v1`）、模型名称和 API Key，各自独立保存、启用和测试。可以使用不同服务商，也可以填写同一服务商的不同模型。地址使用 HTTPS；本机服务允许 localhost/127.0.0.1 的 HTTP。

复盘草稿使用文本配置，成交截图使用图片配置；未配置图片接口时不会自动把图片发送到文本接口。业务页只展示所用配置和功能入口，接口参数仅在设置页编辑。原有单接口配置会按原先实际使用的地址、密钥及模型迁移为两路，直到下一次保存才写入新版配置文件。

两路密钥分别由 Windows 当前用户的系统加密服务保护，仅在主进程解密后用于对应请求，不返回页面、不写进账户备份或日志。修改某一路的服务地址只清除该路原密钥，需要重新输入；不会影响另一路。地址不变时密钥留空表示保留，勾选清除可移除密钥。「保存并测试」保存当前一路后检查连通性，实际图像能力仍需截图检验。

## 保存与恢复

数据目录为 `%APPDATA%\A-trade\workspace\`：

| 文件 | 内容 |
| --- | --- |
| `accounts.sqlite3` | 多账户、流水、快照、复盘、计划与操作审计 |
| `accounts.previous.sqlite3` | 最近一次写入前的一致数据库副本 |
| `workspace-state.json` | 显示设置、旧版笔记及其他演示页面状态 |
| `ai-settings.json` | AI 接口配置和系统加密后的密钥 |

设置中的账本备份导出包含所有账户业务记录，不含 API Key；其中可能含真实财务信息。恢复先验证格式和关联关系，在一个事务里替换账本，失败保留原数据。损坏数据库在有效自动备份存在时保留异常原件并恢复；未来版本数据库拒绝降级写入。自动备份只保留上一次状态，重要节点仍应导出备份。

分享摘要省略结构化账户名称、金额、持仓数量与成交明细；复盘正文中的姓名和金额需在导出前自行检查。

```powershell
npm test
npm run test:business
npm run test:desktop
npm run test:account
```
