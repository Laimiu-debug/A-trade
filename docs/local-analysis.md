# 本地分析工具与市场风格历史

本文所述本地分析从用户所选通达信目录读取，不请求网络，不改写通达信文件，不关联账户交易。
范围包括市场风格及 T01／T04／T07／T08／T09 的本地分析与跟踪能力。
T05 默认同图比较本地板块或分类指数的成交额、5 日热度与区间涨幅，T04 提供候选股成交活跃度观察；
成交活跃度不是主力净流入。资讯、T02 情景估值所需财务、T03 财务筛选和 T05 独立的“主力净流入”入口使用公开接口，
来源与网络边界另见 [公开资讯、财务与行业资金](market-information.md)；情景公式见
[情绪估值参考记录](emotion-valuation-reference.md)。
T06“异动追踪”展示公开来源披露的监管记录与临近截止期限，使用独立的 `market.regulatory.list`，
不属于本地量价分析，也不接受历史 `asOf`；来源、交易日倒计时与核验边界见 [监管与期限追踪](regulatory-watch.md)。
`market.research` 的风格回看支持 60、120、250、500、1000 个交易日，默认 250。
每个显示窗口额外读取 80 根日线进行初始化；实际历史不足时如实显示不足，不补行情。
区间缓存按目录、天数、截至日期分开，刷新会重新校验来源。计算按证券逐只解码，
内存中复用已经校验的原始字节，避免长期保存数百万条字典对象。

普通风格需连续两日确认；防守和覆盖不足即时生效。确认标签最多沿用 20 个交易日，
只有再次连续两日确认（或再次出现即时防守/覆盖不足）才续期。若原始观察长期逐日交替，
旧标签到期后显示“风格待确认”，不会无限保留窗口以前无法证明的标签。
80 根额外窗口覆盖 60 根价格初始化与确认有效期，因此更换历史长度不会用不同旧状态
强行判断相同日期。

## 日期与统计口径

分析请求可传 `asOf: "YYYY-MM-DD"`。读取器只截取该日及以前的数据；休市日或源数据
缺失时返回最近的实际交易日，`requestedAsOf` 保留用户输入，`asOf` 表示实际观察日。
默认使用源数据最近日期，不将其称作实时行情。当前目录不含完整历史上市和退市成分，
因此历史观察存在存续样本偏差。日线未复权，除权等公司行动可能形成异常收益和信号。

收益以公共交易日历上的第 5 / 20 / 60 个交易日前收盘价比较，百分比字段使用百分数。
MA20、MA60 需要相应窗口中完整有效记录。5 日均量比使用当日成交量除以前五个交易日
平均成交量，不含当日；缺日或分母为零时保留未知。缺日不会自动补价格，也不会用
停牌间隔拼接出连续涨停。

市场总览 M01 与连板龙头 T08 共用 `service/leader_research.py` 的全市场连板与接力统计，
包含当前名称 ST。连板计数不再受 60 日趋势样本限制；原有市场广度、阶段收益以及新的趋势指标
仍有各自的历史要求。连板识别要求前一市场交易日和当日均有有效日线、正成交量，且收盘匹配
名义涨停价。T08 的交易板、ST 和最低高度筛选只影响下方候选列表，不改变上方全市场图表与统计。

## 方法

| 方法 | 额外请求字段与默认值 | 结果 |
| --- | --- | --- |
| `market.analysis.overview` | 无 | 候选数量、最近事件、近 60 日高度、跟踪池数量 |
| `market.analysis.trends` | `minReturn20:0`、`minReturn60:0`、`requireAboveMA20:true`、`requireAboveMA60:true`、`minVolumeRatio:0`、`minAmount:0`、`excludeST:true`、`limit:200` | 同日趋势候选，按 20 日收益与成交额排序 |
| `market.analysis.moves` | `kind:"all"`、`changeThreshold:5`、`volumeThreshold:2`、`breakoutDays:20`、`minAmount:0`、`limit:200` | 兼容保留的量价异动：上涨、下跌、放量、收盘突破；`signals` 为匹配类型数组。T06 不以此判定监管 |
| `market.analysis.rebounds` | `minBoards:2`、`minGap:1`、`maxGap:10`、`lookbackDays:60`、`limit:200` | 连板结束后经过指定数量非涨停交易日，再出现首个近似涨停的历史事件 |
| `market.analysis.ladder` | `historyDays:60`、`board:"all"`、`minHeight:2`、`excludeST:true` | 截至日梯队 `groups`、连板候选 `leaders`、昨日高标 `yesterdayLeaders`、共享证据 `leadership` 与历史 `timeline` |

上述本地分析方法均支持 `asOf` 与 `refresh`，不包括独立的监管名单接口。`kind` 可为 `all/rise/fall/volume/breakout`。
`minAmount` 单位为元；`changeThreshold/minReturn20/minReturn60` 使用百分数，5 表示 5%。
突破严格定义为收盘价超过此前 N 个交易日最高收盘价，不冒充盘中突破或最高价突破。
默认趋势条件要求收盘在 MA20、MA60 之上和相应收益不小于 0；不隐含均线多头排列。

统一结果包含 `asOf/requestedAsOf/computedAt/cached/source/provider/coverage/warnings/parameters/items/total`。
`total` 是符合条件的完整数量，`items` 受 `limit` 限制。工具总览仅返回前 12 个趋势例子，
完整候选数量见 `counts`。计算使用日期之前的数据；后续增加价格不会回填较早日的事件。

`items` 包含证券身份、实际日期、收盘、成交额、5/20/60 日收益、均线、5 日均量比等。
断板事件另外包含 `eventDate/priorEndDate/priorBoards/gapDays`；事件日可能早于截止日。
梯队元素为 `{height,items}`；历史元素保留 `{date,maxHeight,limitUpCount,multiBoardCount,observedCount}`，
并增加 `metrics` 与可为空的 `rotationEvent`。`observedCount` 是当日有正成交量的记录数，不能用作晋级率分母。

## 连板龙头与风格切换

T08 页面默认回看 250 日，可选 60／120／250／500／1000 日；接口的 `historyDays` 支持 1–1000，
省略仍为 60。图表共用交易日期，分别展示最高高度、昨日连板及三板以上晋级率、趋势候选成交占比
和 MA20 广度。支持滚轮缩放、左右键拖动、键盘日期预览；点击日期读取当时的梯队，点击证券回看该日日 K。
市场总览的“接力、趋势与风险”随所选历史日期同步，并可跳转到同日连板龙头页面。

当前候选可按全部／主板／创业板／科创板／北交所及当前名称 ST 筛选，页面默认排除 ST、两板起。
接口 `minHeight` 支持 2–10，页面提供 2／3／4／5 板起。最高板候选保留所有并列证券，
同高度按成交额排序；每只展示本轮可观察起点、累计涨幅与昨日高度。`sequenceComplete:false`
表示窗口边缘、缺日或此前名义涨跌幅无法核验，本轮高度和起点只代表已观察部分。
`leaders` 返回达到最低高度的全部候选，页面再取其中最高高度；`groups/items/total` 保留筛选范围内的近似涨停梯队，可能包含首板。

昨日高标先按交易板和 ST 条件筛选昨日两板以上队列，再选择昨日三板及以上；该范围没有三板时回退至两板。
每只分别标记继续晋级、断板或数据缺失，最低高度筛选不隐藏昨日反馈。历史更替事件比较各日的
全市场最高连板候选集合，保留并列名字，记录出现、更替或高度回落；不以今天的候选回填过去。
昨日高标有缺失时，事件附 `incomplete/coverageNote`，页面显示观测不完整，不能据此确认风格切换。

| 证据 | 计算口径 |
| --- | --- |
| 首板→两板、两板→三板、三板以上晋级 | 按昨日高度形成队列；今日继续近似涨停数除以队列中今日可核验数。`all` 仅合并昨日两板以上，不包含首板。 |
| 分母与缺口 | `eligible` 为昨日队列总数，`observed` 为今日可核验数，`missing` 为缺日、无成交或超名义涨跌幅等不可核验数；`rate = promoted / observed`，分母为零返回 `null`。 |
| 断板 | 昨日连板且今日可核验，但今日非近似涨停；未知不算失败。全市场昨日高标按三板以上统计，无三板则取两板。 |
| 昨涨停今日表现 | 昨日全部近似涨停股（含首板）中，前后两日均有正成交量者的今日收盘收益均值／中位数。这里观察实际价格表现，不要求今日涨跌幅处于名义限制内，因此覆盖数可与晋级率不同。 |
| 趋势候选 | 连续 60 个市场交易日有成交，收盘同时高于 MA20、MA60，且最近五日各自的 20 日收益均为正。此口径独立于 T04 可配置的趋势筛选。 |
| 趋势成交占比、MA 广度 | 趋势候选成交额除以连续 60 日有成交样本的总成交额；MA20／MA60 广度为同一样本中站上相应均线的占比。无分母返回 `null`。 |
| 高弹性与风险 | 同一趋势样本中近 10 日涨幅超过 30% 的数量及成交占比；风险另列全市场近似跌停、可比较前收股票中的下跌比例。 |

这些证据并列展示，帮助查看接力与趋势活跃度的变化，不合成为单一“龙头分”或新风格评分。
最高板是价格规则筛出的研究候选；本地日线不包含封单、炸板次数、回封时间和完整行业题材归属。

## 名义涨跌停规则与限制

前收盘价以整数分计算名义限价并四舍五入到分，收盘须匹配该限价；不再把所有超过某涨幅阈值的上涨算作涨停。
实现使用以下日期规则：主板普通股 10%；按当前名称识别的主板 ST 在 2026-07-06 前用 5%、当日起用 10%；
创业板自 2020-08-24 起用 20%，此前普通股 10%、ST 5%；科创板 20%、北交所 30%。
沪深主板 ST 调整及实施日见[上交所发布说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20260424_10816474.shtml)、
[深交所实施通知](https://www.szse.cn/lawrules/service/member/t20260630_621404.html)；创业板规则见
[深交所创业板交易特别规定解读](https://investor.szse.cn/institute/rules/t20200807_580310.html)。

本地目录只有当前证券名称，没有完整历史 ST 身份、上市初期无限价标识、重新上市事件或除权参考价，
因此仍统一标为“近似”，不能替代交易所涨停名单。收盘超出名义涨跌幅时，晋级观察标为规则待核验；
缺日、无成交和不可核验区间都会中断可证明的连板证据，不推断停牌期间情况，也不生成确定断板事件。

## 统一跟踪池

跟踪池使用行情数据库中的独立 `analysis_watchlist` 表，不读取或改动账户持仓。
换行情目录或重新扫描不会清除手工观察记录。首次添加需为当前本地目录已收录证券，
市场前缀必须完整，证券名称取真实目录，不使用调用方传入的演示名称。

- `market.watchlist.list({status?})` 返回 `{items,total}`，省略状态或 `all` 表示全部。
- `market.watchlist.save({symbol,note?,tags?,status?})` 返回保存后的单条记录。
- `market.watchlist.delete({symbol})` 返回 `{deleted,symbol}`，重复移除保持幂等。

状态可为 `watching/planned/holding/archived`；此处 holding 只是手工观察标签，不能代表账户持仓。
备注上限 2000 字，标签最多 8 个，每个 1–20 字。只更新提供的字段，保留其他备注和标签；
每条记录包含 `createdAt/updatedAt`，重启后保留。

## 分析工具优化（2026-10-11）

T04／T07 的 `query/sort/order/offset/limit` 在完整符合规则的候选集合上执行，
然后再分页。页面每页 20 项，搜索及三态排序不再限制于前 200 项；接口未指定分页时
仍保留原默认值。响应增加 `candidateTotal/offset/limit/hasMore`，其中 `candidateTotal`
是搜索前的规则候选数，`total` 是搜索后的数量。T03 财务筛选使用完整公开财务与同日
估值快照，先筛选再分页，详见 [财务目录](market-information.md)。三页均可保存最多
12 组具名常用条件，随桌面工作区持久保存，保存失败会提示。

本地分析与全目录财务整理使用独立计算进程。行情报价、日 K 与跟踪池写入保留独立
交互通道；长分析可查看当前阶段、处理数量并取消，取消后由用户重新读取，不自动重试。
同条件排队计算合并，取消不会中断跟踪池写入。分析特征使用最多 4 组缓存，避免不同
窗口交替调用时反复计算。数据源配置代次和日线数据代次分开：窗口扩大或回看日期改变
本身不改变固定研究的配置身份，源数据更新才使对应研究结果失效。已知的失败刷新状态
保留到成功核验，不因切页或重启而消失。

页面缓存按有效期及北京时间日期重新核验，保留旧结果直到新读取完成。本地分析过期
时会重读来源；主动刷新同步失效相关页面的结果。T02 切换证券清空手填实际市值，
避免将上一只股票的市值代入新的情景计算。

跟踪池默认先展示列表，新增及编辑时打开表单。保存操作包含预读、文件解析与写入全程，
退出时等待完成；旧保存响应不会清掉后来修改的草稿，切页后也会更新当前页面状态。
支持跨页选择候选批量加入，已存在记录不被覆盖。新加入的研究线索保存
`research:{page,asOf,parameters,source}`，保留选中时的日期及条件，不使用最后一页覆盖。

- `market.watchlist.save-many({items})`：原子批量添加，返回 `added/skipped/total/items`。
- `market.watchlist.export({})`：导出全部观察记录为 `a-trade.watchlist`、`schemaVersion:1` JSON。
- `market.watchlist.import({backup,mode:"merge"})`：校验整份备份后事务合并，只添加缺少的证券。

旧版不含 `research` 的备份仍可导入，来源目录已移除也可恢复手工观察。记录上限 5000，
JSON 上限 20 MiB；错误文件及写入失败不会留下部分导入。设置页原有备份接口沿用同一格式。

本轮优化后的整合验证：`npm test` 共 221 项全部通过；`npm run test:business`
共 358 项，356 项通过、2 项因 Windows 符号链接权限跳过。新增回归覆盖跨证券市值隔离、

被失效的迟到响应拒绝、组合页面刷新不循环、备份兼容及事务回滚。

## 当前边界

趋势候选按公开规则计算，不代表已验证的龙头或收益排名；量价异动与近似涨停事件不触发交易，也不能证明进入监管名单。
当前数据未复权、没有完整退市样本及历史证券状态，已实现的名义制度切点不能补齐这些缺口，缺日及无成交会中断连板证据。
本地分析的截至日期只约束所读价格记录，不能证明历史当天软件已取得这些数据；因此尚不
作为完整回测可用性证据。跟踪池保留手工研究记录，没有接入账户自动估值、自动买卖或回测。
