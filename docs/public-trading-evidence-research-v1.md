# 从公开实盘记录建立完整交易体系

状态：Goal 进行中。2026-10-18 根据用户最新方向登记；没有新策略通过验证。

目标是从有出处的实盘行为提炼可复现的方法，服务于“小亏大赚”。先观察真实账户如何选择市场、板块、股票，如何试错、持有、轮动、退出，再冻结规则验证。研究单位仍是完整连续账户。

## 范围与评价

- 2024-09-24 为主要历史分界；之后为主要目标评价区间，之前为熊市压力对照，不要求之前获利。分界后的每个交易日仍需用当时的信息判断实际强弱。
- 顺序：全市场总交易额和流动性、市场强弱 → 强势行业与当时的主线题材 → 龙头、强势股、轮动补涨 → 仓位、现金和退出。
- 盈亏比定义为扣除可归属成本后，完整闭仓交易的盈利收益率均值 / 亏损收益率均值绝对值。分批交易按完整持仓周期归集；部分卖出、浮盈、未卖持仓单列。
- 继承既有研究候选门槛：实现盈亏比至少 3、PF 至少 1.5、平均亏损绝对值不超过 5%、连续账户最大回撤不超过 20%、至少 30 个完整闭仓、主区间扣费后正收益及正基准超额。这些是研究筛选门槛，尚非用户逐项确认的硬性数值承诺。
- 同时检查亏损尾部、连续亏损、利润集中度、仓位、资金容量和多窗口稳定性。结果经过反复观察的历史不得重新称为未见样本。
- 不继续扩展转送、分红记录工程；保留既有数据限制披露。

## 两条证据链

### 真实账户与实盘比赛

查找淘股吧、顽主杯、雪球、东方财富、同花顺等平台。优先主办方比赛档案和账户本人原帖。用户已于本轮说明淘股吧、雪球登录完成；工具能否读取登录态另行核验。

先建立 3 至 5 个证据较完整、方法有差异的账户候选，尽量覆盖至少 100 个完整闭仓周期，作为账本整理里程碑，不是盈利验收标准。冠军、亚军和季军只是发现线索的起点，同时保留完整区间的失败交易、回撤和退赛资料。跨网站转帖、同一人的多个参赛账户不能充当独立样本。

逐条记录：账户与比赛、原文链接及发表时间、成交日期和时间精度、证券代码、方向、数量、价格、费用、出入金、融资、开期持仓、期末持仓与净值。缺项保持未知。截图需逐行核对，不用推算价格填补成交。

每个判断分开保存：

1. 成交或持仓事实：由原始记录支持。
2. 本人解释：标明发言时间，区分交易前计划与事后复盘。
3. 主办方说明：验证声明和点评，不能替代成交单。
4. 研究推断：明确待验证，不能写成交易者真实意图。

只有榜单或收益截图，不计算可信的账户盈亏比。转录平台的收益、回撤和预估手续费属于该平台口径，核对原始交割单和资金流前不视为经审计成绩。模拟比赛、可转债、期货、北交所、杠杆账户分别标记，不直接迁移到当前 A 股无杠杆执行口径。

### 龙虎榜营业部

以沪深交易所披露为优先来源，东方财富等作为整理线索与交叉核对。记录股票、披露日、上榜原因、统计起止日、单日或多日榜、营业部原名、买入额、卖出额和来源。

营业部或交易单元汇总不等于特定个人的完整账户。买卖金额不能还原单人成本、股数、全部持仓或已实现盈亏；未再次上榜不代表清仓。别名与“某游资席位”的归属未经可靠证据不得认定。营业部变更名称按有效日期保留原名及对应证据。

按披露事件观察参与的主线、板块位置、同现营业部、龙头与补涨关系及后续路径。三日累计榜不拆成虚构的每日交易，不与单日榜重复计数。后续收益只能叫事件后的价格表现，不能叫营业部实盘收益率。

龙虎榜在可获得信息之后才允许形成研究信号；只有交易日、无准确发布时间时，保守从下一交易日开始研究可执行入场。不得拿收盘后公布的榜单解释成当日已知信号。

## 从记录到方法

先复原连续行为和大赚前的试错，不围绕最终赢家挑几笔成功案例。对比同一市场、同一板块、相近强度但未交易或交易失败的股票，检验选择是否具有区分能力。缺少完整候选池时，不宣称已识别选股能力。

每个方法登记适用市场、主线认定、龙头/补涨角色、触发、失效、仓位、退出、资金约束、所需数据与原始证据；标清哪些参数来自本人，哪些由研究者为实现规则而定义。规则冻结后才运行新账户，保留失败版本。

现有日线框架只能验证收盘可知、下一可交易时点执行的版本。盘中打板、排队、撤单、回封、做 T 等若缺少对应时间精度和成交可行性资料，只能列为待补证的方法，不能用日线最高/最低价假造原策略成交。

包含成本、T+1、涨跌停与成交容量等约束，进行完整组合及去除关键环节的对照，检查跨窗口与费用/滑点压力。拟合历史冠军行为与验证超额收益是两个不同结果。
