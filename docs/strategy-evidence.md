# 策略证据、扩池验证与预先固定的研究协议

研究日期：2026-10-11。本文区分已读原始研究、待检验假设、当前实现和实验计划；实验数值由真实运行报告提供。文献提供研究理由，不能证明本项目参数已经盈利。

## 网上研究得到的实质结论

A 股的动量与反转取决于观察周期、投资者结构和流动性，证据并不一致。早期沪市样本发现中期动量，后来的 A/B 股比较发现 A 股月度反转，另有研究发现 A 股日度延续但周、月并无相同规律。因此，不把海外动量或期货趋势结论直接当作 A 股选股策略的有效性证明，也不预设“放量越多，未来越好”。

本轮优先验证用户指定的量能金叉与持续优势，并用现有突破、回调、动量作为透明对照。市场状态先做分组描述，不看到结果后立即添加最有利的过滤条件。

## 六项优先候选

这些是依次验证的假设队列，不是六个已盈利的策略。前两项是本轮固定搜索；第三至第五项保留为固定参数对照或下一轮独立研究；第六项本轮只统计状态，不参与选参。

| 优先级 / 候选 | 具体可检验假设 | 原始来源与限制 | 本轮处理 |
| --- | --- | --- | --- |
| P0 / `forceGoldenCross`，量能金叉 | 最少 30 根预热后，上涨日成交量平滑线从下向上越过下跌日成交量平滑线，且 `minDominance` 达标；T 日收盘确认、下一可见交易日开盘尝试进入。检验这一变化是否在成本后提供较好的收益/回撤，而非单纯增加换手。 | 公式来自本机 FINAL-TRADE `backend/app/core/ths_volume_signal.py`；E6 是量价关系研究背景，E2/E4 是必须考虑的 A 股反证。没有论文证明这一特定公式。 | 固定原 MA/EMA 公式，只扫 `minDominance=[0,0.05,0.10]` × `maxHoldingDays=[10,20,40]`，共 9 点。 |
| P0 / `forceTrend`，量能持续优势 | 同一公式的上涨量线持续占优，比单日金叉减少噪声的程度，是否足以抵偿进场推迟与少买机会。 | 同一可审计公式；E2、E6 提供量能持久性和反转的研究动机，不证明持续天数越多越好。 | 固定原公式和 30 根预热；扫 `confirmDays=[2,3,5]` × `minDominance=[0.05,0.10,0.20]`，共 9 点；其他持仓参数固定。 |
| P1 / `trendBreakout`，此前区间突破及量能消融 | 在同一趋势/风险设置下，真实突破此前高点是否优于仅趋势过滤；增加量比门槛究竟减少假突破还是错失低量延续。 | E5 支持技术规则的可检验性，E4 要求保留“量能没有额外帮助”的可能；不是复现其市场指数策略。 | 现有规则作为固定对照。若下一轮测试量比，在独立协议固定 1.0、1.2、1.5 后做消融，不能本轮看到最佳阈值再追加扫描。 |
| P1 / `trendPullback`，趋势内回调修复 | 在仍向上的趋势中，适度回撤后出现收盘回升，是否较追高更适合当前 A 股样本；检验亏损是否集中于趋势反转。 | E1/E2 的 A 股反转证据是研究动机；“上升趋势中的回调”与原论文横截面反转组合并非同一策略。 | 现有默认规则作独立对照。与突破条件组合前先检查逻辑互斥，不用永不触发的 AND 交集制造安全假象。 |
| P2 / 中期动量与跳过近期收益的对照 | 比较固定中期观察期、以及剔除最近约一个月收益后的排名，检验短期反转是否掩盖中期延续。 | 同时依据 E1、E3、E4 的相互制约；E9 只提供跨资产趋势背景。 | 现有 `momentum` 不含跳月，不能把当前结果称为跳月动量。新增变体需要独立版本和新的训练/留出协议，月度调仓、只做多及成本必须明确。 |
| P2 / 市场状态与波动风险约束 | 检验同一冻结策略是否在弱广度、高波动、快速反弹阶段集中失效；后续才研究只用过去数据的仓位降低规则。 | E7/E8 是状态风险研究依据，不是本项目过滤阈值的证明。 | 本轮只生成状态分组与风险描述，不改变买卖决定。未来候选必须另行预注册；不将事后选出的“只在赢家环境交易”收益写成可实现业绩。 |

“主力/散户”是原指标的命名。实际输入只是涨跌日成交量：上涨日分配到一条序列，下跌日分配到另一条序列；分别经过 MA(3) 后再用 EMA(3) 与 EMA(10) 平滑。它既不识别投资者身份，也不等于逐笔主动买卖净额。`dominance=(上涨量平滑线-下跌量平滑线)/(两线之和)`，不是机构持仓比例。

## 扩大到固定 50 股的验证协议

### 1. 先固定样本，再查看策略成绩

从本机可见的 A 股文件构造候选清单，排序/分层只使用截至 **2022-12-30** 的信息。计划按该日前最近 60 个可见交易日的成交金额中位数进行流动性分层，固定五组、每组十只，共 50 只。组内抽样/排序方法、稳定种子或代码顺序须写入 manifest，并在算策略收益前保存所选代码及其数据指纹。无历史成交金额时不得用未来成交金额补选。

这是对当前本地文件集合的历史流动性分层，不自动恢复 2022 年当时的完整上市及退市股票集合。因此仍需列出当前文件覆盖、历史不足、缺失/损坏记录及所有排除原因，不把该池描述为“无偏全 A 股”。不能根据 2023 年之后的涨幅选择股票，也不能根据最终回测亏损或数据质量失败再悄悄替换证券。

最低历史覆盖规则只能看截至选样日的记录；未来停牌、退出或数据中断留在报告中。若单个文件后来确认损坏，修订数据集需要新版本和原排除清单，不能覆写旧实验。与上一轮六股示例的重合数量另列，区分扩大覆盖与完全新样本。

### 2. 固定时间边界

研究范围采用 **2023-01-03 至 2026-10-09**，指标预热可读取此前历史。两项 P0 搜索共享同一组日期、股票和数据质量处理规则。主运行沿用 `PlateauRunner` 的固定顺序切分：默认最后 20% 可见交易日为最终留出，之前分成三个时间块；保存真实的 `split.training`、`split.blocks` 和 `split.holdout` 起止日。

自动等分不等于自然年度切分。2023、2024、2025 与 2026 年截至截止日的统计可额外作为日历分段描述，但不能用其中表现较好的年份替换预先固定的三个训练块。若实验脚本改成自然年度训练和 2026 年留出，应在运行前明确记录新协议，不能把两套拆分里较有利的一套当唯一结果。

已有六股研究使用过同一段历史；本轮“留出”严格指不进入自动参数评分的部分，不宣称整个市场历史此前从未被人查看。最终筛选结论仍需后续新数据验证。下一次看到留出后调整规则，必须将该段标为已暴露，不能继续称作全新检验。

### 3. 冻结参数与搜索预算

```json
{
  "forceGoldenCross": {
    "strategyParams.forceGoldenCross.minDominance": [0, 0.05, 0.10],
    "maxHoldingDays": [10, 20, 40]
  },
  "forceTrend": {
    "strategyParams.forceTrend.confirmDays": [2, 3, 5],
    "strategyParams.forceTrend.minDominance": [0.05, 0.10, 0.20]
  }
}
```

主协议固定 18 个参数组合，每组分别在三个训练块运行；训练子回测为 54 次。有合格区域才运行冻结代表点的留出及双倍成本，每个策略最多再增加两次子回测。默认配置对照、数据版本重跑、消融和此前六股试验也进入总试验登记，不能只报告获胜的 18 点。

运行前将完整 `normalize_config` 输出保存，明确资金、最多持仓数、单股仓位、止损、全部/部分止盈、移动止损、固定持有期、成交容量及费用。除上表列出的两个轴外，不改变其他参数；`forceTrend` 的 `maxHoldingDays` 也必须明确冻结。成本压力只将 `costMultiplier` 翻倍，保留对应日期的自动税费规则。没有实际执行的对照项目记为“未运行”，不计入已完成次数。

现有平原默认每块至少三个完整退出样本，这只是运行门槛，不是统计充分性的证明。正式报告必须列出实际交易数、覆盖的证券数、平均持有期与资金曝光；样本不足时不降低门槛以得到推荐。若要提高最低样本门槛，应在本次查看结果前固定，并将其作为协议字段保存。

### 4. 先通过数据质量，再解释收益

必须分别保存原始开高低收和公司行动/历史状态的来源、取得时间、覆盖期间及内容指纹。原始价格用于真实成交价格和涨跌停边界；复权/公司行动处理用于连续性及收益口径时，需要与份额、现金分红和成本账本一致，不能简单把后复权价直接当真实可成交价格。

本地发现 `gbbq` 文件只是有一个待解析来源，不意味着已具备完整总回报数据。应核对解码有效性、事件类型、除权日期、现金/送转比例及不支持类型，保留未知项。某些小额除息不一定越过价格跳变阈值，所以“没有触发异常”不能等同于“公司行动已处理完整”。支付日期、配股选择、退市回收和历史 ST 信息缺失时要保留范围限制。

当前平原会拒绝含 `quality.quarantinedSymbols`、`metrics.staleValuationDays > 0` 或 `quality.unaccountedActionExposure=true` 的训练块及最终检验；最后一项表示策略持仓经历了未入账现金/股数权益的公司行动。仅基准存在公司行动暴露不否决策略，但 `excessReturnReliable=false` 时不能据此作可靠超额收益结论。不能用正收益覆盖具体坏数据。修复真实数据问题可以重新运行，但需保留修复前后版本和结果，避免以“清洗”之名删除亏损事件。扩池导致无合格区域时，正确结果可以是无推荐。

### 5. 固定市场状态标签，先描述后研究

若没有可信、对齐的市场指数，用 **本次固定 50 股样本广度**，不得标为全市场广度。对每个收盘日 `t`，仅在当天有有效成交且具备 60 根连续有效历史的样本股票中，计算收盘高于自身 60 日均线的比例 `B_t`；分母数量和缺失率一并保存。

后验报告按事先固定阈值标记：`B_t >= 0.60` 为强广度、`B_t <= 0.40` 为弱广度，其余为中间状态；有效分母少于固定池的一半时标记“覆盖不足”，不强行分类。它描述固定样本股票的状态，不是官方牛熊市定义。

若要给交易的风险来源分组，入场依据使用信号收盘时已知的 `B_t`，不得使用未来持有期结束时的标签。可以另列实际每日组合收益在各状态中的贡献，但这种归因不是把非连续日期抽出来重跑的可交易业绩，也不应把各状态收益简单相加为复利总收益。

本轮不增加指数/广度买卖过滤，不根据标签挑选赢家时段。以后若测试波动率或广度过滤，阈值、滞后方式、分母定义和仓位变动要在新的训练窗口内固定；作为新候选计入试验总数。

## 平原还需要哪些证据

现有方法已把训练分块、邻域评分和最终留出分开，并且可以诚实给出无平原。它衡量的是本次已采样网格的表现，不提供统计显著性、多重检验校正或未来收益概率。

新增的行为辨识诊断用于防止误解“完全平坦”：每个训练块保存成交与净值曲线的 SHA-256 摘要；`diagnostics.distinctBehaviorCount` 给出网格中不同执行路径的数量，`inactiveAxes` 给出在固定其他参数后没有改变路径的轴。所有点的路径完全相同则标记 `uninformative=true`。例如所有止损阈值在上涨样本中都没触发，平坦只能说明样本没有区分它们，不能证明精细选参成功。

这一诊断保留原推荐代表点和原有通过门槛，不把相同配置自动判坏；`validation.parameterIdentifiability` 和 `interpretationWarnings` 保留解释边界。也不能只比较最终收益判定路径一致：相同终值可以来自不同交易和回撤，所以比较完整已观察的成交与净值路径。

固定 18 点的实验完成后，至少同时展示：训练块分数/样本数、区域及代表点、不同执行路径数量、最终留出与双倍成本结果、相同股票池基准、最大回撤、持仓曝光、成交/拒单比例、数据质量失败以及所有未通过候选。单个尖峰、高胜率或一段上涨行情中的正收益，不足以把策略命名为“优质盈利策略”。

结果文件应附完整配置、冻结 manifest、引擎/策略/平原版本、源文件指纹、开始与结束时间、已有试验登记及真实运行次数。本文只固定研究依据和审计口径，不预写实验结论。
