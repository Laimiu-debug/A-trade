# 情绪周期与完整收益平原

## 情绪周期工具

入口：分析工具 → 情绪周期。读取已配置、已扫描的通达信本地日线，不改写行情文件或账户交易。

页面提供观察日期、前后交易日、返回最新、60/120/250/500/1000日历史、排除当前ST名称、刷新、
连板梯队跳转、证券历史日K和加入跟踪池。历史柱状时间线显示最高板与已确认阶段，点击日期重新读取当时及以前数据。

阶段名称参考低位试错、主升、高位震荡、主跌的公开讲解，以及龙头、补涨、切换的观察框架：

- [2021-04-02 直播“周期与时机”回放转载](https://www.bilibili.com/video/BV16N4y127C3/)：搜索可检索到对应回放，未取得可独立核验的完整字幕。
- [四阶段原帖的文字转载](https://m.tgb.cn/a/274STO5sg7W?type=hot)：页面注明转载92科比2020-07-02帖子，原帖发布身份未独立核验。
- [2021-04-07 直播整理与作者个人解读](https://xueqiu.com/7735440616/176435731)：第三方资料，不作为本人逐字原文。

产品数值规则不声称是92科比原版公式，也没有用收益最大化拟合阈值。全部规则随接口返回，可在页面展开核验。
只有日线数据，不能确认盘中封单、炸板回封、人气或带动因果。

`market.analysis.sentiment({asOf?,historyDays:120,excludeST:true,themeId:"",refresh:false})`
通过独立计算进程执行，返回 `current/timeline/leaders/yesterdayLeaders/lowCandidates/themes/rotationCandidates/rules/references`。

- 至少10个此前交易日、20只有效股票和70%覆盖才判断阶段。少于1000只有效股票始终标注“目录样本周期”。
- 昨涨停溢价、连板晋级率、高标失败率使用昨日固定队列，不用今天幸存榜单倒算分母。
  可核验队列少于3只或覆盖低于70%时不参与阶段判断。原始队列及缺失数保留在 `metrics`。

- 缺日、无成交、超名义涨跌幅不算确定断板。实际观察日与请求日期分开返回。

- 不重叠题材中，旧题材昨日3板以上高标过半断板、新题材至少两只低位涨停时，显示“切换待验证”。
  这项线索不等于新主线已经形成。

## 题材归属

点击“记录题材归属”，填写名称、至少两只证券和生效日期；也可读取当前通达信板块成分后保存。
记录为独立的 `emotion_themes` SQLite快照，保留来源、生效日期、保存时间，重启后恢复。
证券必须在当前本地股票目录，单份2–500只、最多100份。修改归属应保存新快照，已有快照不覆盖。

- `market.emotion.themes.list({})`
- `market.emotion.themes.save({name,symbols,effectiveFrom,source:"manual"|"tdx_snapshot"})`
- `market.emotion.themes.delete({id})`

当前板块快照禁止向历史回填，最早从当天生效。手工补录历史归属会标明“事后手工标注”，
不能视为当时已知成分，且不会接入策略回测信号。生效前的日期不显示该快照。
AI上下文使用同一实际截止日，不附以后交易日、目录路径或账户凭据。

## 按需分析单只龙头

右上角 AI 是统一提问入口。空间龙头候选、同题材空间高标和昨日高标行内的「分析此股」直接打开同一个面板并分析所选股票；已有回答只恢复，不重复请求。进入页面、打开全局面板、切换日期、刷新情绪观察、保存模型配置均不触发 AI 或额外日线读取。

使用「设置 → AI 模型」中已保存并启用的文本模型。发送时在本地证券目录识别问题中的完整股票名称或代码，最多补充3只、每只最近120根真实日线；不分析未提及的其余候选。支持完整年月日和日期范围；未指定日期时使用页面截止日。名称有歧义或代码不存在时保留问题并提示补全，不猜测证券。停牌或非交易日保留最后实际交易日；没有区间数据则阻止发送。日线可能按用户已有行情设置走在线回退，不自动补新闻或题材。

结果统一显示在右侧对话，可追问、查看本次实际材料、停止、失败重试或开启新话题。「返回本页对话」恢复页面问答与原草稿。页面、日期、题材筛选、股票与行情目录隔离会话；读取日线期间范围改变会阻止发送，停止后的迟到数据或回答被忽略。对话只在本次启动内保留。用「这只股」「那天」追问时沿用上次股票与截止日。

问题日期与页面不同，或个股选择日早于已加载最新日线时，剔除页面指标、筛选与交易结果，仅发送指定日期内的实际日线并说明未重算情绪/题材/回测；更晚日期的对话不进入历史问题材料。材料区明确列出股票、实际日期和日线数量。情绪历史只保留阶段与判断证据，按上下文预算裁剪，避免大对象导致整个结构化数据被丢弃。

策略工作区同步当前可见表格（最多3表、每表20行16列），随分页和筛选更新；操作、私密备注和笔记列不进入材料。没有结果日期时明确标注未知；涉及单股日线则移除日期无法核对的旧页面结果。宽屏打开右侧AI时，策略工作区一并收窄，保持内容可见。

验证：`node --test tests/emotion-leader-ai.test.cjs`、`npm run test:emotion-ai`。原生桌面测试仅调用本机隔离的 AI 测试服务，验证零自动请求、逐只请求、重复点击、停止、重试、历史截止日与安全渲染。

目录只有当前上市证券和当前名称，历史ST身份、退市成分、复权和题材归属仍存在限制。

## 完整收益平原

收益平原参数区提供一键生成7×7（49点）、11×11（121点）、21×21（441点）。
生成止损3%–13%和止盈5%–35%的完整二维网格，其余参数固定为当前回测设置。
可以直接编辑各参数列表；每轴最多64个唯一值，完整网格最多2000个组合。

默认使用11×11完整网格。旧草稿按原值恢复，如果全部列表为空，页面明确提示只有一个点，
要求至少两个变化轴后再启动平原。非法、越界或过长列表不会静默删除或改成其他坐标。

`sampling_mode:"grid"` 评估全部笛卡尔积，`sample_points/max_points` 不再截断网格前缀。
超2000点在任务创建/执行前拒绝，用户可缩小范围或改用区间采样。
`sampling_mode:"lhs"` 继续按各轴最小/最大范围抽样，点数1–2000，适合高维研究。
单次扫描内，日线指标按证券、截止日、窗口和规则版本缓存，保留有界容量并复制可变对象；
每个参数组合的入场、退出、持仓与收益仍独立计算，不复用其他组合的成交结果。
热力图只展示实际已计算坐标，不插值补成未计算的收益。稳定区仍须通过现有硬过滤，
没有合格稳定区就没有推荐参数。历史报告保留原计算范围，不伪装成完整新网格。

验证命令：`npm test`、`npm run test:strategy-ui`、`node scripts/smoke-emotion-grid.cjs`。
桌面验收使用隔离TDX夹具、真实Electron/IPC/Python引擎，提交并完成121个不同坐标的实际回测。
