# A-trade 浅色设计令牌初稿

版本 V0.5，2026-10-11。默认浅色主题已确认；以下数值作为 UI 初稿，后续随页面评审调整。本版将专属图标扩展至应用主标识、按钮、功能入口和状态反馈，里程碑外观沿用 V0.4。其余视觉基础、连续通行证轨道和多任务令牌沿用此前方案，不包含应用实现代码。

整体使用白色工作面和浅灰背景，蓝色表达操作与选中状态，红绿表达行情方向。图表与表格保留充足空间，装饰集中在账户收益通行证。目标收益率和阶段数由用户设置，不属于固定视觉令牌。页面方案见 [UI 设计初稿](ui-design-draft.md)。

## 视觉总览

### HTML 预览追加：可调节视觉效果

2026-10-11 根据用户要求，前端预览加入玻璃、光效、粒子与渐变。入口为“设置 → 显示与交互”，支持独立开关、总开关、即时预览、本地保存和恢复默认；正式应用后续沿用评审确认后的值。

| 项目 | 默认 | 调节范围 |
| --- | --- | --- |
| 磨砂模糊 | 18px | 0–32px |
| 卡片不透明度 | 78% | 55–100% |
| 光效强度 | 42% | 0–100% |
| 背景粒子数 | 24 | 0–60，通行证与设置样例按密度补充少量局部粒子 |
| 粒子速度 | 35% | 0–100%，0 为静止 |
| 渐变浓度 | 48% | 0–100% |
| 渐变方向 | 125° | 0–360° |
| 默认双色 | `#4778F5` / `#9D7AEE` | 蓝紫、蓝青、粉紫预设及自定义颜色 |

预设包括“清透日常”“流光氛围”“专注阅读”。玻璃作用于卡片、导航和弹窗；光效与粒子集中在背景、通行证及设置样例。行情涨跌色、文本色和图表语义不被配色替换。装饰层不捕获输入，减少动态效果遵循应用与系统偏好，页面隐藏时暂停动画。不支持背景模糊时使用接近实色的卡片降级。

总览通行证标题简化为“里程碑”。进度条追加 HUD 微刻度、3.8 秒扫描流光和 2.6 秒端点脉冲，强度跟随柔和光效设置；减少动画时保留静态刻度与光点。装饰不改变实际进度长度。

后续细节修订弱化分块感：导航与顶栏共用背景氛围，卡片取消高对比白色描边与明显阴影，资产数字采用连续分组。里程碑详情以右侧日期时间线承载交易与事件，不再只展示目标资产。

- 过长股票名称可省略，但同一单元格保留名称与代码，悬停和键盘聚焦显示完整名称。

### 波段里程碑徽章

统一采用切角六边形银边、浅层蓝色晶面和白色波浪折带纹样。图案保持大块留白，小尺寸减少晶面数量；当前及重要节点增加尺寸或边框层次。六种主题为视觉候选，不是六项新的业务成就。

| 图案主题 | 造型 |
| --- | --- |
| 启程 | 单道上扬波浪折带与短基线。 |
| 积累 | 两道交叠折带。 |
| 逐浪 | 连续抬升的波峰。 |
| 突破 | 穿过几何拱门的波浪折带。 |
| 远峰 | 三道高低错落的山峰形波浪。 |
| 长程 | 环绕波浪的轨迹与双层边缘。 |

| 状态或层级 | 表现 |
| --- | --- |
| 未达成 | 银蓝低饱和晶面，中心纹样仍清晰；按需查看目标时明确显示未达成。 |
| 已达成 | 蓝色晶面、白色纹样和小勾号，文字说明可通过悬停或聚焦查看。 |
| 当前进度 | 保持原图案，略放大并附局部进度弧及“当前”；不使用完成勾号。 |
| 重要节点 | 加强双层银蓝边框；这是视觉层级，可与未达成、当前或已达成状态组合。 |

图案身份、业务状态和节点重要程度分别定义。同一节点变化时只更新材质、标记与光效，不突然换成另一种图案。进度弧依据真实阶段进度绘制，口径未确定或数据缺失时不显示虚构比例。六种图案不限制用户设置的阶段数量，节点用实际序号识别；超过六阶段可复用主题，重要节点的分布方案另行评审。

主轨道不新增图案名称卡、奖励框或参数。悬停沿用 160ms 轻抬，达标沿用 700ms 单次点亮；重要节点 900ms，终点 1100ms。再次浏览已完成阶段不重播，减少动态时直接展示状态。后续实际制作建议将边框、晶面、纹样、状态标记和光效分层，以便清晰缩放及独立动画；当前交付仅为设计图与规范。

## 动画

| 令牌 | 时长 | 应用 |
| --- | --- | --- |
| motion.instant | 0ms | 精确金额、实时状态和键盘操作的直接反馈。 |
| motion.fast | 120ms | 按钮、导航、表格行悬停。 |
| motion.normal | 180ms | 页签、折叠区、状态转换。 |
| motion.panel | 240ms | 抽屉、对话框进入与退出。 |
| motion.chart | 320ms | 首次呈现曲线，轴、图例和数值立即稳定显示。 |
| motion.passBrowse | 180ms | 滚轮结束后的平滑收尾，连续输入及拖动即时跟随。 |
| motion.passHover | 160ms | 徽章悬停轻抬，位移最多 4px，不改变相邻节点布局。 |
| motion.passProgress | 600ms | 真实进度更新时光带推进及一次高光扫过。 |
| motion.milestone | 700ms | 新达标阶段节点点亮及连线推进。 |
| motion.passCheckpoint | 900ms | 重要里程碑徽章点亮一次，数值始终稳定。 |
| motion.passComplete | 1100ms | 整本通行证完成时展示终点徽章一次，不遮挡工作区。 |
| motion.easing.standard | cubic-bezier(0.2, 0, 0, 1) | 常规进入与状态转换。 |
| motion.easing.exit | cubic-bezier(0.4, 0, 1, 1) | 面板退出。 |

- 通行证首次显示轻淡入；真实进度更新时光带推进，新达标里程碑再点亮徽章。悬停时最多 4px 轻抬；重要与终点徽章各有一次强化效果，重新打开历史页面不重复庆祝。
- 轨道只在有效输入、真实进度变化和达标事件时播放相应动效；不循环扫光或持续呼吸。离屏时不播放装饰动画；减少动态模式保留直接滚动和状态更新。
- 页面转换以短淡入或内容区域切换为主；跨股票不整窗滑动，避免打断分析位置。
- 抽屉进出最大位移 12px；背景内容保持稳定。
- 曲线首次可短暂描线；切换指标、拖动十字线和缩放时直接呈现结果，不重播整条历史。
- 进度条在已报告的进度之间做 120ms 过渡，文字显示真实数值；不能确定总量时显示阶段和已完成数量。
- 任务完成使用勾号与一次淡入提示；暂停和停止在实际生效后改变状态，请求处理中有文字说明。
- 多任务进度使用相同时长但不同时启动装饰动画；批量完成合并提示，任务行保持位置。暂停和继续请求先显示实际处理中状态，不提前改变为已暂停或运行。
- 默认不播放数字滚动、持续闪烁、无限呼吸、自动轮播和装饰粒子。操作路径播放属于用户主动功能，默认暂停，可逐日步进。
- 读取系统减少动态效果偏好，并提供软件内开关。减少动态模式取消位移、描线和成就高光，保留即时状态反馈。动画规范参考 [W3C 交互动画说明](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)。

### HTML 预览颜色与交互校准（2026-10-11）

精确语义色集中在 `preview/tokens.css`，各业务模块统一使用既定主蓝和中性色；紫/青/金用于比较序列，金融涨跌和功能状态按语义区分。装饰渐变独立，不改动图表数据色。窄侧栏必须保留子页面图标与名称提示；模块支持再次点击收起。里程碑筛选保持浮层实例与焦点，禁止重复入场闪动。任务删除有独立垃圾桶图标、撤销提示和回收站恢复入口。

### 无边框窗口与滚动控件（2026-10-11）

用户要求取消窗口边框与右侧突兀的系统滚动条，所有滚动条和范围滑块采用项目风格，并尽量减少数量。

- 桌面窗口使用应用内顶栏，窗口按钮融入浅色界面；顶栏空白可拖动，最小化、最大化/还原及关闭保持可用。
- 主页面隐藏右侧滚动条，保留滚轮、触控板和键盘滚动；不以裁切内容代替滚动。
- 页面采用一个主要纵向滚动区域；页签优先换行，配置区随页面展开，弹窗只由内容区滚动。
- 长表格、侧栏和抽屉确需滚动时使用纤细的蓝灰圆角滑块、透明轨道和无箭头样式。
- 范围滑块沿用项目主蓝、细轨道和圆形拖动点，保留键盘焦点、禁用状态和足够的操作区域。
- 面板通过留白与底色分层，减少外框线；输入控件、选中状态和键盘焦点保留清晰的识别方式。
