# 第一批实盘方法证据与待验证问题

2026-10-18；研究笔记，不是已通过验证的交易规则。

## 二池：少数大赚与大量试错

[本人 2024-12-12 原帖](https://m.tgb.cn/a/2dVOWdW2Lpm)说明，全年主要盈利来自少数操作，并非所有交易都有效。原帖支持“需要研究盈利来源和试错过程”，不提供可直接执行的完整买卖条件。

[本人交割照片原帖](https://m.tgb.cn/a/28kIGuZznWH)中的分批买入、部分卖出和滚动操作，说明不能把每一行卖出视为一次独立交易。六张照片有重叠，展示并不覆盖完整查询区间。它们早于 2024-09-24，只用于学习与核对转录。

[比赛主办方 2024-10-29 日评](https://m.tgb.cn/a/2cKq8cYE5Co)同时记录过其买入受挫与卖出行为。此类点评属于主办方观察；没有价格和数量时，不等同于成交账本，也不能据此补出止损规则。

待验证：大赚前的试错次数与金额；同一主线内重复交易与最终盈利的关系；盈利主要来自持有时间、加仓、切换还是盘中差价；未出现大赚时的持续亏损与资金占用。取得完整账本前不计算其净实现盈亏比。

## 请叫我小蟒夫：周期、个股角色与仓位一起判断

[本人 2022-01-27 汇总](https://m.tgb.cn/a/1LOJjiwIO3y)明确把指数位置、情绪转折和新旧龙头衔接一起讨论；不同市场阶段对应不同的试错规模。原文还区分低位寻找入场与高位持仓管理，并讨论预期失效后的退出。

这支持一种体系层面的研究方向：先判断市场和主线所处阶段，再确定个股角色与机会，最后决定是否交易、使用多少仓位及何时退出。它并不支持“每天照着某种连板形态买入就能赚钱”的结论。

[本人“经典弱转强”原帖](https://m.tgb.cn/a/1G487Wvm8GQ)可作为入场条件的原始材料；具体规则仍需结合对应交易、当时市场和题材情况检验。2021—2022 年的解释不是 2024 年以后已有效的证据。

待验证：大周期与板块周期如何形成交易前可知的分类；龙头打开空间之后，哪些较低位置的股票具有补涨资格；弱转强失败时的亏损尾部；收益改善来自择时、选股、仓位还是退出。没有历史候选池、准确分钟数据和可成交性证据时，不以当天最高最低价还原盘中成交。

## 营业部：研究参与条件，不能反推个人账本

已从上交所官方页面使用的公开接口取得主区间首个完整季度的披露。按官网表格定义分开保留普通买卖排名、融资融券会员报告、严重异常波动投资者分类；后两种不能塞进普通营业部买卖表。

统计频率只用于找出值得继续观察的营业部原名。同名匿名机构、跨日累计区间、同股多原因上榜及不同客户共同使用一个营业部，都会妨碍将这些记录视为独立交易。全季度排名属于事后描述，不能拿来充当季度开始时已经知道的跟踪名单。

待验证：其参与是否集中在当时的主线与核心股；同一题材是继续加强、内部切换还是撤出；披露后市场反应能否在真实可执行价格下复现。席位净买入、后续涨幅和营业部实际收益必须分开。
